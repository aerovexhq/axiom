# 内存原生静态检查规则

Axiom EDA 内置了实时内存原生静态分析检查器 (`crates/lsp/src/linter.rs`)。在编写代码的同时，静态检查器即可深入分析抽象语法树与网表连通性，秒级检测综合风险、仿真竞争冒险与电气违规。

---

## 静态诊断规则目录

```
+-------------------------------------------------------------------------------+
| Axiom Static Linter Dashboard (Problems Dock)                                 |
| 0 Errors | 2 Warnings | 1 Informational | Real-Time Latency: 1.8 ms           |
+-------------------------------------------------------------------------------+
| [AXIOM_W001] Line 42: Blocking assignment (=) inside clocked sequential block |
| [AXIOM_W007] Line 88: Case statement missing default branch                   |
+-------------------------------------------------------------------------------+
```

### 1. `AXIOM_W001`：时序逻辑过程块中误用阻塞赋值
- **严重程度**：警告 (Warning)
- **违规行为**：在边沿触发的时序过程块（`always @(posedge clk)`）中使用了阻塞赋值 `=` 而非非阻塞赋值 `<=`。
- **潜在风险**：引入仿真器调度相关的竞争冒险，寄存器在被更新前或更新后被读取完全取决于线程事件执行顺序。
- **修复措施**：将 `=` 替换为 `<=`。

### 2. `AXIOM_W002`：组合逻辑过程块中误用非阻塞赋值
- **严重程度**：警告 (Warning)
- **违规行为**：在电平敏感的组合逻辑块（`always @*` 或 `always @(a or b)`）中使用了非阻塞赋值 `<=`。
- **潜在风险**：造成不必要的零时间 delta 周期 (δ周期) 调度开销，并可能引发仿真与综合行为不一致。
- **修复措施**：将 `<=` 替换为 `=`。

### 3. `AXIOM_W003`：悬空无驱动网线
- **严重程度**：警告 (Warning)
- **违规行为**：已声明的 `wire` 网线没有任何持续驱动源（`assign`）、逻辑门输出或子模块端口驱动。
- **潜在风险**：该网线在物理上永久悬空，仿真中表现为高阻态 (`Z`) 或未知态 (`X`)。
- **修复措施**：为网线连接有效驱动源，或移除未使用的网线声明。

### 4. `AXIOM_W004`：无扇出冗余信号
- **严重程度**：警告 (Warning)
- **违规行为**：声明并被写入赋值的信号从未被下游任何逻辑锥读取。
- **潜在风险**：浪费芯片硬件硅片面积，并在综合时产生无意义的冗余门电路。
- **修复措施**：删除无用信号定义，或将其连通至目标接收端。

### 5. `AXIOM_E002`：多驱动源总线电气冲突
- **严重程度**：错误 (Error)
- **违规行为**：多个持续赋值语句或多个驱动源同时驱动同一根 `wire`。
- **潜在风险**：在物理硅片上会导致短路烧毁；在仿真中解析为竞争冲突未知态 (`X`)。
- **修复措施**：插入多路复用器 (MUX)，或确保任何时刻仅由单一驱动源控制该网络。

### 6. `AXIOM_W006`：组合逻辑推断出意外锁存器
- **严重程度**：警告 (Warning)
- **违规行为**：在组合逻辑过程块中，目标变量在某一个或多个条件执行路径分支中未被赋值。
- **潜在风险**：综合工具将强制推断出异步电平敏感锁存器，引入严重的时序收敛困难并对时钟毛刺高度敏感。
- **修复措施**：确保所有变量在每一个 `if-else` 分支内均被明确赋值，或在 `always @*` 顶部赋予预设默认值。

### 7. `AXIOM_W007`：case 语句缺少 default 分支
- **严重程度**：警告 (Warning)
- **违规行为**：`case` 语句未声明 `default:` 兜底分支。
- **潜在风险**：未被覆盖的输入向量组合将导致意外锁存器推断，或导致状态机发生死锁停滞。
- **修复措施**：添加 `default: <safe_state>;` 兜底分支。

### 8. `AXIOM_W008`：端口或赋值位宽不匹配
- **严重程度**：警告 (Warning)
- **违规行为**：左侧网线的声明位宽与右侧表达式计算出的位宽不一致。
- **潜在风险**：高位有效位被静默截断，或发生非预期的零扩展/符号扩展错误。
- **修复措施**：显式对齐位宽，或使用切片位选运算符精确截取。
