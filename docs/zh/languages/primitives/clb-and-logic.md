# 可配置逻辑块 (CLB) 与逻辑原语

可配置逻辑块 (CLB) 包含了 Xilinx FPGA 的核心查找表 (LUT)、快速进位逻辑以及时序存储单元。

---

## 查找表 (`LUT1` 至 `LUT6`, `LUT6_2`)

### 1. `LUT6_2` (双输出 6 输入查找表)
现代 Xilinx CLB 的基石。它可实现任意单个 6 输入布尔函数 (`O6`)，或共享输入 `I0` 至 `I4` 的两个独立 5 输入布尔函数 (`O5` 与 `O6`)：

```verilog
LUT6_2 #(
    .INIT(64'h8000_0000_0000_0000) // 6-input AND gate
) u_lut (
    .O6 (and_out),
    .O5 (), // Unused in single-output mode
    .I0 (in0), .I1 (in1), .I2 (in2),
    .I3 (in3), .I4 (in4), .I5 (in5)
);
```

---

## 快速进位链逻辑 (`CARRY4`, `CARRY8`)

专用快速进位链用于实现高速加法器与累加器，避免进位信号经过较慢的通用布线资源：
- **`CARRY4` (7系列)**：4 位超前进位宏单元，包含传播信号 (`S[3:0]`)、生成信号 (`DI[3:0]`)、进位输入 (`CI`) 与进位输出 (`CO[3:0]`, `O[3:0]`)。
- **`CARRY8` (UltraScale+)**：8 位超前进位宏单元，每个 CLB 切片提供两倍的进位逻辑密度。

## 触发器与锁存器 (`FDRE`, `FDSE`, `FDCE`, `FDPE`)

Xilinx 切片寄存器支持专用时钟使能与优先级置位/复位：

| 原语名称 | 触发条件 | 复位类型 | 优先级 | 功能描述 |
| :--- | :--- | :--- | :--- | :--- |
| `FDRE` | `posedge C` (时钟上升沿) | 同步复位 (`R`) | 复位优先 | 带时钟使能 (`CE`) 与同步复位的 D 触发器 |
| `FDSE` | `posedge C` (时钟上升沿) | 同步置位 (`S`) | 置位优先 | 带时钟使能 (`CE`) 与同步置位的 D 触发器 |
| `FDCE` | `posedge C` (时钟上升沿) | 异步清零 (`CLR`) | 清零优先 | 带时钟使能 (`CE`) 与异步清零的 D 触发器 |
| `FDPE` | `posedge C` (时钟上升沿) | 异步预置 (`PRE`) | 预置优先 | 带时钟使能 (`CE`) 与异步预置的 D 触发器 |

```verilog
FDRE #(
    .INIT(1'b0) // Power-on initial value
) u_ff (
    .Q  (q_out),
    .C  (clk),
    .CE (clk_en),
    .R  (sync_rst),
    .D  (d_in)
);
```
