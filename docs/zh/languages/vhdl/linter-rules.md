# VHDL 语言服务器与诊断规则

Axiom EDA 集成了专用的 VHDL 语言服务器（`crates/lsp/src/vhdl.rs`），在 Monaco 编辑器内直接提供实时语法校验、类型一致性审计以及设计规则检查 (DRC)。

---

## VHDL 诊断规则集

| 规则编号 | 严重程度 | 功能描述 | 修复建议 |
| :--- | :--- | :--- | :--- |
| `VHDL_W001` | 警告 | **敏感列表不全**：在组合逻辑进程中被读取的信号未包含在敏感列表中。 | 将遗漏的信号添加到 `process(...)` 列表中，或直接使用 `process(all)` (VHDL-2008)。 |
| `VHDL_W002` | 警告 | **意外推断出锁存器**：组合逻辑进程中不完整的分支判断（`if-then-else` 或 `case-when`）会意外推断出透明锁存器。 | 补全所有可能分支，或在条件分支前为信号赋予预设默认值。 |
| `VHDL_E001` | 错误 | **类型不匹配**：试图在未显式转换的情况下将 `std_logic_vector` 直接赋值给 `unsigned` 或 `integer`。 | 使用显式类型转换函数：`to_integer()`、`unsigned()` 或 `std_logic_vector()`。 |
| `VHDL_W003` | 警告 | **未使用的悬空信号**：已声明的内部信号从未被赋值或读取。 | 移除多余的死信号声明。 |
| `VHDL_E002` | 错误 | **多驱动总线冲突**：多个并行赋值语句同时驱动同一个解析信号，导致电气竞争。 | 改用单一的多路复用赋值逻辑。 |
