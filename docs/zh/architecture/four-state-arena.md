# 4态逻辑空间

硬件描述语言需要完整的 IEEE 1800 4态逻辑空间语义：
- `0`：强低电平逻辑。
- `1`：强高电平逻辑。
- `X`：未知或未初始化逻辑电平（冒险或总线冲突）。
- `Z`：高阻态（三态悬空网线）。

天真地使用 8 位或 32 位枚举来表示逻辑状态会破坏 CPU 缓存局部性，并阻碍位并行 SIMD 矢量操作。

---

## 双向量位并行编码

Axiom 将所有电路网线布局在连续的内存空间（`SimStateArena`）中，采用双字位编码表示：

| 逻辑值 | `value` 位 | `mask` 位 | 功能描述 |
| :--- | :---: | :---: | :--- |
| **`0`** | `0` | `0` | 确定低电平 |
| **`1`** | `1` | `0` | 确定高电平 |
| **`X`** | `0` | `1` | 未知 / 未初始化状态 |
| **`Z`** | `1` | `1` | 高阻态 / 未连接 |

### 内存布局
- 为 `values: Box<[u64]>` 和 `masks: Box<[u64]>` 分配连续的 64 位对齐内存块。
- 一个 32 位网线在两个向量中占据相同的偏移量 $i$。
- 读取或写入网线仅需一次 $O(1)$ 复杂度的指针偏移解引用。

### 按位逻辑运算
通过使用双向量，4态布尔逻辑运算可以在所有 64 位上同时并行执行：

```rust
// 4-State Bitwise AND:
// result_val  = val_a & val_b
// result_mask = (mask_a & (val_b | mask_b)) | (mask_b & (val_a | mask_a))

let res_val = val_a & val_b;
let res_mask = (mask_a & (val_b | mask_b)) | (mask_b & (val_a | mask_a));
```
这使得宿主机 CPU 每个时钟周期能够执行数以千计的位逻辑操作。
