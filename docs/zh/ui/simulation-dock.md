# 仿真命令功能区与统一操作面板

Axiom 仿真控制系统将超高速执行引擎与直观的命令功能区及底部统一操作面板 (`BottomConsole.tsx`、`UnifiedBottomDock.tsx`) 相结合。它提供了对物理仿真时间与离散 delta 周期的直接掌控。

---

## 顶部仿真命令功能区

顶部标头工具栏显示仿真遥测数据与控制按钮：

```
+-------------------------------------------------------------------------------+
| [ Run ] [ Pause ] | [ +1 ns ] [ +100 ps ] [ Step Delta ] | [ Reset (t=0) ]    |
| Time: 125,400 ps (125.4 ns) | Delta: 0 | Core: 0.988 V | Power: 34.2 mW       |
+-------------------------------------------------------------------------------+
```

### 控制操作
- **运行 (`Space` / `Ctrl + Enter`)**：在后台 Web Worker 或内存中 Cranelift JIT 编译引擎中以高频启动连续自主时钟节拍。
- **暂停 (`Space`)**：瞬间挂起仿真执行，冻结所有信号跟踪曲线与寄存器状态以供检查。
- **+1 ns (`F10`)**：将物理仿真时间精确向前推进 1,000 皮秒。
- **+100 ps (`Shift + F10`)**：将物理仿真时间向前推进 100 皮秒以进行高精细时序分析。
- **单步 Delta (`F11`)**：步进单个离散零时间 delta 周期 (δ周期)（$\delta \to \delta + 1$）而不增加物理仿真时间，精确暴露组合逻辑竞争冒险与中间门级跳变。
- **重置 (`Ctrl + R`)**：将仿真时间倒回至 $t=0$，将信号向量重置为初始状态，并保留已编译的设计，以便立即恢复执行而无需重新细化。

## 底部统一操作面板标签页

可折叠的底部面板组织了必不可少的辅助工程工具：

### 1. 控制台与交互式 REPL
- 显示编译器处理阶段、AST 细化指标以及活动模块实例。
- 实时流式传输来自 Verilog 仿真的 `$display`、`$write` 和 `$monitor` 输出内容。
- 提供交互式命令行提示符，用于评估信号表达式或查询网线状态值。

### 2. 问题与静态检查诊断
- 列出当前活动的静态分析警告与语法错误。
- 显示规则编号（`AXIOM_W001` 等）、严重程度徽标以及源文件名。
- 点击任意问题卡片即可使 Monaco 编辑器立即定位跳转至对应的代码出错行。

### 3. 遥测雷达
- 显示核心供电电压、电感性 PDN 电压骤降 (IR + L di/dt)、供电电流与动态功耗散逸的实时模拟仪表。

### 4. 波形面板
- 当主可视化窗格聚焦于原理图、虚拟硬件实验台或静态时序分析 (STA) 雷达时，渲染辅助波形预览。
