# 静态时序分析 (STA) 与时序雷达

Axiom EDA 内置全功能的静态时序分析 (STA) 引擎与交互式时序雷达可视化工具 (`crates/sta`)。它在可综合网表上执行拓扑路径传播计算，对照目标时钟约束评估建立与保持时间裕量，并在物理实现前准确识别关键路径性能瓶颈。

---

## 静态时序分析 (STA) 引擎架构

STA 引擎将电路网表分解为由时序节点与时序边构成的有向无环图 (DAG)：
- **时序节点**：逻辑门引脚、触发器输入端（`D`、`CE`、`R`）、触发器输出端（`Q`）以及顶层 I/O 端口。
- **时序边**：单元内部传播延迟 ($t_{\text{logic}}$) 与线网互连布线延迟 ($t_{\text{route}}$)。

### 时序裕量数学公式
对于始于源端触发器 ($FF_1$) 并终于目的端触发器 ($FF_2$) 的每条时序路径：
$$\text{Data Arrival Time} = T_{\text{clk1}} + t_{\text{cq}} + t_{\text{logic}} + t_{\text{route}}$$
$$\text{Data Required Time} = T_{\text{period}} + T_{\text{clk2}} - t_{\text{setup}} - t_{\text{skew}} - t_{\text{jitter}}$$
$$\text{Setup Slack} = \text{Data Required Time} - \text{Data Arrival Time}$$

当时序裕量满足 $\text{Slack} \ge 0$ 时，该路径时序收敛；负裕量 ($\text{Slack} < 0$) 则表示存在时序违例，需要进行逻辑精简或插入流水线寄存器。

### 1. 时序关键指标 (KPI)
- **最差负裕量 (WNS)**：所有时序终点中的最差裕量值。若 WNS 为负数，则设计无法在目标时钟频率下可靠运行。
- **总负裕量 (TNS)**：所有违例时序终点的负裕量绝对值总和，反映了全工程整体时序压力的严重程度。
- **违例时序终点数**：未满足建立或保持时间要求的寄存器或输出端口总数。

### 2. 关键路径瀑布流表格
详尽显示构成最大传播延迟路径的单元逻辑跳变与互连布线跳转的精确物理时序序列。每一行清晰列出元件名称、增量延迟、累积到达时间与剩余时序裕量。

### 3. 裕量分布直方图
直观展现整个设计中所有时序终点裕量的统计分布情况。位于 0 ns 竖线左侧的区间直观标出了急需优化的违例路径。

## 跨时钟域 (CDC) 同步机制

STA 引擎会自动分析包含多个异步时钟域的设计：
- 检测无关异步时钟之间未经过寄存器打拍采样的信号直连穿越。
- 精准识别并验证两级与三级触发器同步链 (`cdc_sync`)。
- 将未施加时序异常约束的 CDC 路径标记为高危亚稳态风险。
