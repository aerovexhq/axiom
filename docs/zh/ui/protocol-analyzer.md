# 协议分析仪与串行数据包分析

Axiom EDA 配备内建的硬件串行协议分析仪与数据帧解析器 (`crates/sim/src/protocol/`, `ProtocolAnalyzer.tsx`)。它能在内存中直接监测数字信号跳变、提取数据帧结构、校验和校验，并解码标准通信总线的数据包载荷。

---

### 1. UART（通用异步收发器）
- 可自由配置波特率（从 9600 至 921600 Baud）。
- 数据位：支持 5、6、7、8、9 位配置。
- 奇偶校验：支持无校验 (None)、偶校验 (Even)、奇校验 (Odd)、Mark 及 Space 校验。
- 停止位：1、1.5 或 2 位。自动检测帧格式错误 (Framing Error) 与间隔中断标志 (Break Condition)。

### 2. SPI（串行外设接口）
- 支持 MOSI 与 MISO 全双工数据流同时同步解码。
- 完整支持所有 4 种 SPI 时钟工作模式：模式 0 ($CPOL=0, CPHA=0$)、模式 1 ($CPOL=0, CPHA=1$)、模式 2 ($CPOL=1, CPHA=0$) 以及模式 3 ($CPOL=1, CPHA=1$)。
- 支持低电平有效或高电平有效的片选信号 (`CS_N`) 选通判决。

### 3. I2C（内部集成电路总线）
- 支持 7 位与 10 位从机设备寻址模式。
- 准确识别起始条件 (START)、重复起始条件 (Repeated START) 与停止条件 (STOP)。
- 严格校验从机应答 ACK/NACK 比特以及数据传输方向位（读 / 写）。

### 4. CAN 总线 2.0A / 2.0B
- 车规级控制器局域网 (CAN) 协议数据帧深度解析。
- 位填充检测与自动化解填充 (De-stuffing) 恢复算法。
- 支持 11 位标准标识符与 29 位扩展标识符解析提取。
- 数据长度代码 (DLC) 验证与 CRC-15 多项式校验和硬件校验。

### 5. USB 1.1 / 2.0
- 低速 (1.5 Mbps) 与全速 (12 Mbps) NRZI 差分总线状态机跟踪。
- USB 比特位逆填充恢复。
- 包标识符 (PID) 深度解码：令牌包（OUT、IN、SOF、SETUP）、数据包（DATA0、DATA1）以及握手包（ACK、NAK、STALL）。
- 支持令牌包 CRC-5 与数据包 CRC-16 多项式硬件校验。

### 6. 以太网 MII / RMII
- 10/100 Mbps 介质独立接口 (MII/RMII) 帧解析器。
- 以太网帧拆解分析：前导码 (`0x55`)、帧起始定界符 (`0xD5`)、目的 MAC、源 MAC 以及以太网类型。
- 支持 IPv4 报头解析、ARP 协议与 UDP 报文有效载荷提取。
- 帧校验序列 (FCS) CRC-32 循环冗余校验。

## 数据包检查器抬头显示 (HUD)

- **事务流数据表**：清晰按序展现数据包传输事务，包含时间戳、通道标识符以及校验状态徽标。
- **载荷十六进制 / ASCII 查看器**：以格式化的十六进制字节网格或清晰的 ASCII 字符表示细致审查二进制载荷。
- **错误故障标记**：损坏异常的数据包（校验和失败、帧格式错误、奇偶校验违规）以醒目的红色警告徽标高亮标示。
