# 微架构检查与 Multi-Die MCM 可视化

Axiom EDA 提供专用的微架构深度内省工具 (`crates/ir/src/microarch/`, `MicroarchViewer.tsx`, `MultiDieViewer.tsx`, `PpaParetoViewer.tsx`)。这些工具能自动识别处理器数据通路、算术逻辑单元、寄存器堆和有限状态机，并支持前沿的 2.5D/3D 多 Die (Chiplet) 芯粒先进封装。

---

## 自动化数据通路识别推断

RTL 细化器主动审查模块拓扑结构，自动提取标准微架构逻辑功能块：

```
+-------------------------------------------------------------------------------+
| Microarchitecture Datapath Detector:                                          |
| Detected: 1 ALU (32-Bit) | 1 RegFile (32x32) | 1 FSM Controller (5 States)     |
+-------------------------------------------------------------------------------+
| ALU Inspector Modal:                                                          |
| - Opcode: 4'b0010 (ADD) | Operand A: 0x0000_0020 | Operand B: 0x0000_0014     |
| - Result: 0x0000_0034   | Zero Flag: 0           | Overflow: 0                |
+-------------------------------------------------------------------------------+
| FSM Bubble Diagram: [IDLE] --start--> [READ] --ready--> [EXEC] --done--> [IDLE]
+-------------------------------------------------------------------------------+
```

### 1. ALU 算术逻辑单元检查器
自动识别多路选择器驱动的算术运算单元。高亮显示当前生效的操作码选择（ADD、SUB、AND、OR、XOR、SLL、SRL、SRA、SLT）并实时标出寄存器操作数取值。

### 2. 寄存器堆 (RegFile) 检查器
精准检测多端口寄存器内存数组（`reg [31:0] registers [0:31]`）。提供交互式 32 行网格数据视图，实时呈现所有架构寄存器的十六进制内容，并伴随写入选通的高亮提示。

### 3. FSM 状态机气泡图可视化 (`FsmViewer.tsx`)
自动解析提取有限状态机 (FSM) 的状态向量与状态转移矩阵：
- 渲染包含状态气泡圆球与转移条件箭头的交互式有向图。
- 在实时动态仿真运行期间，实时荧光点亮当前处于激活状态的状态气泡。
- 深度审计 FSM 拓扑结构：自动检测不可达孤立状态、死锁陷阱终端状态以及缺少默认恢复分支的漏洞。

## 2.5D 与 3D Multi-Die 硅芯片先进封装

针对前沿的 Chiplet 芯粒与多 Die 先进封装架构（例如 AMD UltraScale+ 堆叠硅互连 SSI 技术）：
- **中介层 (Interposer) 芯片版图**：直观呈现连接多个有源逻辑 Die (SLR) 的硅中介层版图。
- **Die 间互连走线 (SLL 超长线)**：深入分析跨越物理 Die 边界微凸块 (Micro-bump) 的连接带宽、传输延迟与时钟偏斜。

---

## PPA 帕累托综合权衡分析器

PPA 分析器对照三项核心工程指标对硬件设计进行全面权衡评估：
- **功耗 (mW)**：动态开关功耗与静态漏电能耗总和。
- **性能 (MHz)**：基于静态时序分析 (STA) 推导得出的最高可达成时钟工作频率。
- **面积 (LUT / FF)**：占用的芯片物理资源总量。

可视化工具绘制帕累托最优配置前沿曲线，便于设计团队在给定的高吞吐或低功耗运行指标下选取最优的流水线深度平衡点。
