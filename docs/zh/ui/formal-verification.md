# 形式化属性验证 (FPV) 工作台

Axiom EDA 配备引擎内建的限界模型检查器 (BMC) 与 $k$-归纳法形式化验证套件 (`crates/sim/src/formal/`, `FormalVerificationViewer.tsx`)。与可能遗漏隐蔽极端边界情况的伪随机测试向量不同，形式化验证能在数学上对所有可能输入场景下的 SystemVerilog 断言 (SVA) 进行严格的证明或证伪。

---

## 限界模型检查 (BMC) 与 k-归纳法

```
+-------------------------------------------------------------------------------+
| Formal Verification Studio: Bound Depth K = 20 | Mode: k-Induction           |
| Proven: 8 | Falsified: 1 (Counterexample) | Witnessed: 4 | Inconclusive: 0    |
+-------------------------------------------------------------------------------+
| Verification Goals:                                                           |
| Status    | Goal Name           | Type   | Bound | Time (ms) | Trace          |
|-----------+---------------------+--------+-------+-----------+----------------|
| [PROVEN]  | p_fifo_no_overflow  | assert | K=20  | 14.2 ms   | -              |
| [PROVEN]  | p_fsm_legal_state   | assert | K=20  |  8.1 ms   | -              |
| [FALSIFY] | p_ack_within_4_cyc  | assert | K=12  | 24.8 ms   | [View Trace]   |
| [WITNESS] | c_fifo_full_reached | cover  | K=8   |  5.3 ms   | [View Trace]   |
+-------------------------------------------------------------------------------+
```

### 1. 限界模型检查 (BMC)
BMC 将硬件状态转移关系沿 $k$ 个离散时钟周期进行有限展开 ($s_0 \to s_1 \to \dots \to s_k$)。引擎评估是否存在任何可达状态会违背断言。如果在 $j \le k$ 步检测到非法状态，引擎会精确提取出一条 **反例证明轨迹**。

### 2. $k$-归纳法（完备性数学证明）
$k$-归纳法证明：如果某个属性在前 $k$ 个基础步内恒成立，且假设其在任意连续 $k$ 个步骤序列下成立时必定在第 $k+1$ 步也成立，则该属性在无限时间 ($t \to \infty$) 内获得 **无条件完备证明**。

## 自动化结构完整性验证目标

在形式化工作台中打开设计时，Axiom 会自动综合生成基准的结构性安全属性，无需工程师手写繁琐的 SVA 代码：
- **`p_no_unknown_out`**：证明在复位释放后，顶层输出端口绝不会跳转至高阻态 (`Z`) 或未确定态 (`X`)。
- **`p_fsm_state_valid`**：证明独热码与二进制状态寄存器绝不会陷入未定义或非法的状态向量中。
- **`p_reset_stability`**：证明在复位信号有效期间，内部所有寄存器均能可靠维持预定的复位初值。
- **`c_fsm_active`**：自动生成覆盖性属性 (Cover)，证明状态机声明的每一个状态在实际运行中均具备可达性。

## 反例时间轴回放与波形跟踪注入

当断言验证失败时，Axiom 会自动生成长度最小化的反例证明波形：
- **逐周期步进回放器**：使用信号差分表逐步回放导致断言违背的每个时钟周期，清晰展示触发故障的具体网线。
- **一键波形注入**：点击 **注入轨迹至波形视图**，可直接将反例跟踪轨迹载入主波形查看器中，并将时间游标精确停留在发生违约的时钟周期上。

## SVA 属性向导弹窗 (`SvaAssistantModal`)

形式化工作台内置了直观的交互式 SVA 属性向导助手 (`SvaAssistantModal`)：
- **即时断言 (Immediate Assertions)**：简单的不变量断言（`assert (ready == 1);`）。
- **请求-应答握手协议**：`req |-> ##[1:4] gnt`，确保应答信号必须在预设的有限周期内准时到达。
- **FIFO 先进先出顺序验证**：严格验证写入的数据以完全一致的先进先出顺序在输出端读取呈现，不发生任何损坏错乱。
- **停顿总线稳定性验证**：确保当 `stall` 挂起有效时，数据总线保持恒定稳定值（`stall |-> $stable(data)`）。
