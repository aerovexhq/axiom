# 门级技术映射 (Tech Mapping) 工作台

Axiom 门级技术映射工作台 (`crates/ir/src/synth/`) 架起了行为级 RTL 与物理 FPGA 架构之间的桥梁。它将通用布尔逻辑方程、多路选择器和算术运算符分解映射为 AMD/Xilinx 7 系列与 UltraScale+ 器件原生的底层硬件原语。

---

## 特定硬件架构原语降阶映射

```
+-------------------------------------------------------------------------------+
| RTL Verilog Code:                       | Mapped Silicon Primitives:          |
|                                         |                                     |
| assign F = (cond) ? (a + b) : (c & d);  | - LUT6_2 (INIT = 64'hE2E2_0000_...) |
|                                         | - CARRY4 (Fast Arithmetic)          |
|                                         | - FDRE   (D Flip-Flop with Enable)  |
+-------------------------------------------------------------------------------+
```

### 支持的 FPGA 芯片目标
工程师可从预先配置好的硬件架构库中自由选择目标芯片：
1. **AMD Artix-7 (XC7A35T / XC7A100T)**：6 输入 LUT、CARRY4 进位链、DSP48E1 切片以及 RAMB36E1 嵌入式块内存。
2. **AMD Kintex-7 (XC7K325T)**：高速高性能 7 系列硬件架构。
3. **AMD Zynq-7000 (XC7Z020)**：集成双核 ARM Cortex-A9 处理系统的 7 系列可编程逻辑架构。
4. **AMD Kintex UltraScale+ (XCKU5P)**：现代 16nm FinFET 制程架构，配备 CARRY8 进位链、DSP48E2 乘加单元与 UltraRAM 存储块。
5. **Axiom 虚拟硅片 (Virtual Silicon)**：专为高校教学与敏捷原型设计优化的高容量通用虚拟硬件架构。

## 布尔逻辑网络分解与 K-LUT 映射

### 1. $K$-LUT 逻辑分解
Axiom 将任意布尔逻辑表达式分解为具有 $K$ 个输入的查找表 (LUT) 网络（现代 Xilinx 芯片中 $K=6$）：
- 具有 $\le 6$ 个唯一样本输入的子逻辑直接映射入单个硬件 `LUT6` 原语中。
- 共享多达 5 个输入的双输出逻辑函数自动聚合映射为双输出 `LUT6_2` 原语（利用 `O5` 与 `O6` 双输出）。
- 输入变量宽于 6 的超宽逻辑函数 ($N > 6$) 通过香农展开定理 (Shannon Expansion) 分解为级联 LUT 树状网络。

### 2. 精确 `INIT` 十六进制参数计算
每个被映射的查找表都将其完整逻辑真值表序列化为一个 64 位十六进制 `INIT` 参数字：
$$\text{INIT}[i] = f(i_5, i_4, i_3, i_2, i_1, i_0)$$
例如，一个 2 输入与门（AND）映射到 `LUT6` 时，其计算参数为 `INIT = 64'h0000_0000_0000_0008`。

## 宏原语模式智能推断

综合映射引擎能够自动识别 RTL 中的高级结构性行为模式：
- **DSP 硬件单元推断 (`DSP48E1` / `DSP48E2`)**：多比特乘法（`a * b`）、乘加运算（`P = P + (A * B)`）以及前置加法器序列被直接映射至专用硬件 DSP 单元，避免消耗数百个通用逻辑 LUT。
- **块状内存推断 (`RAMB18E2` / `RAMB36E2`)**：带有同步时钟驱动的解包数组内存（`reg [31:0] mem [0:1023]`）被自动降阶映射为真双端口或简单双端口硬件 Block RAM。

## 映射后网表审查与结构化 Verilog 导出

技术映射查看器提供全面的后综合透视特性：
- **资源利用率柱状图**：清晰呈现 Slice LUT、Slice 寄存器 (FF)、CARRY 进位链、DSP 切片及 Block RAM 的消耗数量与百分比。
- **单元检查器数据表**：检索、过滤和定位所有已映射的底层物理原语实例。
- **真值表 HUD 浮窗**：实时审查任意已映射 LUT 内部所承载的精确布尔逻辑真值表。
- **结构化 Verilog 导出**：一键生成例化标准 Xilinx 底层原语的纯结构化门级网表源码 (`.v`)。
