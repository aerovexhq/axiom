# Monaco HDL 代码编辑器与语言服务器

Axiom HDL 代码编辑器将微软 Monaco 编辑器与内存原生 Verilog、SystemVerilog 和 VHDL 语言服务器协议 (LSP) 守护进程 (`crates/lsp`) 深度集成。它将语法高亮、实时静态设计规则检查、AST 语法树悬停提示和自动补全代码片段融为一体，构建出航天级的 IDE 开发体验。

---

## Monarch 硬件描述语言分词器

Axiom 具备专为 IEEE 1364 Verilog、IEEE 1800 SystemVerilog 和 IEEE 1076 VHDL 语法定制研发的 Monarch 分词器。

### 视觉样式风格 (`axiom-dark`)
编辑器采用 Axiom 的深色调色板进行样式渲染：
- **关键字**（`module`、`always_ff`、`assign`、`wire`、`reg`）：高对比度青色 (`#00f0ff`)
- **系统任务与系统函数**（`$display`、`$finish`、`$time`、`$clog2`）：紫色 (`#a855f7`)
- **字符串**：琥珀黄 (`#fbbf24`)
- **数值与定宽字面量**（`8'hFF`、`1'b0`、`32'd100`）：翠绿色 (`#34d399`)
- **注释**（`//`、`/* ... */`）：柔和石板灰 (`#64748b`)
- **标识符与信号名**：柔白 (`#f1f5f9`)

## 实时内存原生静态代码检查器 (Linter)

与需要耗时数分钟编译流水线才能标记语法错误或设计隐患的传统工具不同，Axiom 的静态检查器在内存中持续运行，具备 250ms 的防抖窗口。

### 内置静态设计规则

| 规则编号 | 严重程度 | 规则名称 | 说明与所防范的设计隐患 |
| :--- | :--- | :--- | :--- |
| `AXIOM_W001` | 警告 | **时序逻辑中使用阻塞赋值** | 在时钟触发块（`always @(posedge clk)`）内部使用阻塞赋值（`=`）会引入仿真与综合前后的竞争冒险隐患。 |
| `AXIOM_W002` | 警告 | **组合逻辑中使用非阻塞赋值** | 在组合逻辑块（`always @*`）中使用非阻塞赋值（`<=`）会造成多重 delta 周期竞争冒险与综合不匹配。 |
| `AXIOM_W003` | 警告 | **悬空未驱动网线** | 声明的线网或网线没有连接任何持续赋值驱动源 (`assign`)、原语输出或子模块驱动端。 |
| `AXIOM_W004` | 警告 | **未使用信号** | 声明的寄存器或线网已被写入或定义，但从未在任何下游逻辑锥中被读取。 |
| `AXIOM_E002` | 错误 | **多驱动源信号冲突** | 多个持续赋值语句或并发驱动源驱动同一条网线，造成电气短路与不确定态 `X` 信号冲突。 |
| `AXIOM_W006` | 警告 | **意外推断出透明锁存器** | 不完整的分支条件语句（`if` 缺少 `else`，或 `case` 缺少覆盖所有分支）会导致意外推断出透明锁存器。 |
| `AXIOM_W007` | 警告 | **Case 语句缺少 Default 分支** | `case` 语句未包含 `default:` 默认分支，存在未覆盖状态向量陷入死锁的风险。 |
| `AXIOM_W008` | 警告 | **位宽不匹配** | 左值与右值表达式之间的线网或端口赋值位宽不一致，导致静默的高位截断或补零。 |

波浪下划线会直接标记在编辑器中有违规的语法词元下方。在 **问题与静态检查** 面板中点击任意错误卡片，可立即使编辑器光标跳转至对应的行与列。

## AST 语法树悬停信息卡片

将鼠标悬停在编辑器中的任意标识符上，会弹出交互式 AST 语法元数据提示卡片：
- **信号声明**：显示网线类型（`wire`、`reg`、`logic`）、位宽范围（`[31:0]`）以及有符号性。
- **驱动源位置**：显示对该信号进行赋值驱动的具体代码行号。
- **Xilinx 原语技术文档**：悬停在硬件原语（`LUT6_2`、`DSP48E2`、`RAMB36E2`、`BUFG`、`CARRY8`）上可直接查看完整的引脚定义文档、真值表参数与行为说明。

## 智能代码自动补全

Axiom 语言服务器提供毫秒级智能自动补全：
- **IEEE 1364/1800 关键字**：自动生成 `module`、`always_ff`、`always_comb`、`case` 以及 `generate` 的结构框架代码。
- **系统任务**：为 `$display`、`$monitor`、`$finish` 以及 `$dumpvars` 提供预设格式的参数模板。
- **作用域内信号**：智能联想当前活动模块层次结构中声明的所有线网、寄存器与参数。
- **Xilinx 7 系列 / UltraScale+ 原语**：为底层硬件单元生成完整的端口映射例化模板。

## 编辑器人性化与状态持久化

- **多标签页文件管理**：支持同时打开多个设计源文件。活动文件标签页在浏览器刷新后依然保持状态。
- **面包屑路径导航**：编辑器上方的路径栏清晰显示当前工程、文件集、活动文件以及父级模块。
- **视口位置持久化**：Monaco 编辑器的滚动位置（垂直行号与水平偏移）在 `localStorage` 中按文件缓存，重新切回文件时可精确恢复上次的视口焦点。
