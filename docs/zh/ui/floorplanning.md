# 硅片布局规划 (Floorplanning) 与 Die 版图工作台

Axiom EDA 配备交互式二维硅芯片 Die 布局规划工作台 (`crates/ir/src/floorplan/`, `FloorplanStudioViewer.tsx`)。它可以在真实的 FPGA 芯片版图上直观呈现物理单元放置、硅片站点网格、互连飞线以及热力与逻辑密度热图。

---

## FPGA 硅片芯片架构网格

布局规划器精确渲染目标 FPGA 硬件架构的真实站点网格：

```
+-------------------------------------------------------------------------------+
| Top I/O Bank (IOB)                                                            |
+---+-----------------------------------------------------------------------+---+
| L | CLB Slice Grid (SliceL / SliceM)   | DSP Column | BRAM Column         | R |
| e | [x][x][x][ ][ ][ ][x][x][x]        | [DSP48E2]  | [RAMB36E2]          | i |
| f | [x][x][ ][ ][ ][ ][x][x][x]        | [DSP48E2]  | [RAMB36E2]          | g |
| t |------------------------------------+------------+---------------------| h |
|   | Global Clock Center Spine (BUFG / Clock Center)                       | t |
| I |------------------------------------+------------+---------------------|   |
| O | [x][x][x][x][ ][ ][ ][x][x]        | [DSP48E2]  | [RAMB36E2]          | I |
| B | [x][x][x][x][ ][ ][ ][x][x]        | [DSP48E2]  | [RAMB36E2]          | O |
+---+-----------------------------------------------------------------------+---+
| Bottom I/O Bank (IOB)                                                         |
+-------------------------------------------------------------------------------+
```

### 芯片物理站点类型
- **CLB Slice (SliceL 与 SliceM)**：包含 LUT 与触发器的逻辑切片。SliceM 站点还额外支持分布式 RAM 与移位寄存器 (SRL)。
- **DSP 专用列**：跨越多 Tile 的专用物理列，布置高速 `DSP48E2` 硬件算术单元。
- **块状 RAM 专用列**：专为 `RAMB36E2` 和 `RAMB18E2` 嵌入式双端口内存预留的垂直专用列。
- **外围 I/O Bank**：环绕四周的左、右、上、下 I/O 缓冲器 (`IOB`)，将封装物理管脚连接至内部逻辑。
- **时钟主干 (Clock Spine)**：中央水平时钟分配走线槽，容纳全局时钟缓冲器 `BUFG` 与低抖动平衡时钟布线网络。

## 解析放置器 (HPWL) 与进位链聚集算法

综合放置器通过解析二次放置算法与半周长线长 (HPWL) 最小化计算每个单元的最佳物理坐标 $(x, y)$：
$$\text{HPWL}(e) = \max_{v \in e}(x_v) - \min_{v \in e}(x_v) + \max_{v \in e}(y_v) - \min_{v \in e}(y_v)$$

### 垂直进位链专用列聚集
需要高速硬核进位链 (`CARRY4` / `CARRY8`) 的算术宏单元不能在芯片版图上任意分散放置。放置器会自动将相关进位单元沿专用的硅片高速进位走线聚集在连续的垂直列中。

## 硅片逻辑密度与功耗热力图

整个芯片版图面积被离散划分为标准化的 $32 \times 32$ 空间 Tile 网格矩阵：
- **利用率热力图**：根据逻辑单元占用密度，Tile 从深海蓝（空置 / 低利用率）渐变至鲜艳琥珀色与红色（高拥塞度 $>85\%$）。
- **热力耗散图**：结合逻辑开关翻转率 ($\alpha$) 与局部放置密度，直观展示硅芯片上的瞬态热耗散集中热点。

---

## 曼哈顿布线飞线与关键路径荧光覆盖

- **点对点曼哈顿飞线**：点击任意单元即可点亮直角折线的曼哈顿正交布线通道，清晰指向其驱动的所有下游扇出目的端。
- **关键路径荧光图层**：静态时序分析 (STA) 引擎所检测出的最差时序违约路径，被渲染为一条醒目的荧光橙色轨迹，从源端触发器跨越芯片版图延伸至目的端终点。
