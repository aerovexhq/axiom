# 高密度数字波形与逻辑分析仪

Axiom EDA 配备基于 HTML5 Canvas 加速渲染的高密度 60+ FPS 数字波形查看器与逻辑分析仪。它使工程师能够审查多信号时序关系、展开总线数制基数、精确测量时序间隔并捕捉零时间 delta 周期内部毛刺。

---

## 分层数字波形时间轴

波形查看器采用垂直虚拟化滚动渲染数字波形跟踪轨迹，即便容纳数百条信号也丝毫不产生 UI 卡顿：

```
Signal Name   Radix   | 0 ns      5 ns      10 ns     15 ns     20 ns     25 ns
----------------------+--------------------------------------------------------
clk           1-bit   | _/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_
rst_n         1-bit   | _____/=================================================
data_in[7:0]  Hex     | = 00 =X= 41 =X= 42 =X= 43 =X= 44 =X= 45 =X= 46 ======
valid_in      1-bit   | ______/===========\___________/=======================
busy_out      1-bit   | ____________/===========\___________/=================
----------------------+--------------------------------------------------------
                      |       |<---- Delta-T: 10.0 ns (100.0 MHz) ---->|
```

### 信号显示功能特性
- **数制基数切换**：右键单击或点击任意信号的数制胶囊标签，可在 **十六进制**、**二进制**、**无符号十进制**、**有符号十进制** 与 **ASCII** 之间自由切换。
- **总线展开**：点击任意多位向量（`data[7:0]`）旁边的箭头展开折叠按钮 (`>`)，即可展开查看每个独立的信号位线。
- **彩色高亮显示**：单比特逻辑电平以高对比度青色渲染，总线以琥珀色渲染，未知态与高阻冲突态（`X`、`Z`）以鲜明红色渲染。

## 现代拖拽式测量测量窗口

Axiom 彻底替代了传统繁琐的双光标测量方式，带来了直观高效的拖拽式测量窗口：

1. **点击并拖拽**：在波形时间轴的任意区域横向拖拽，即可框选并高亮测量窗口。
2. **边界控制手柄 ($[A, B]$)**：拖拽左侧或右侧边界控制手柄，以皮秒级精度微调测量起止点。
3. **平移测量窗口**：拖拽测量窗口正中心，即可沿时间轴整体滑动该测量时间区间。
4. **实时测量 HUD 浮窗**：HUD 浮窗即时计算并显示：
   - **时刻 A ($T_A$)**：起始时间戳，带有紧凑工程单位（ps、ns、us、ms）。
   - **时刻 B ($T_B$)**：终止时间戳。
   - **时间差值 ($\Delta t$)**：测量区间的持续时间精确值（$\Delta t = |T_B - T_A|$）。
   - **等效频率 ($f$)**：对应的等效时钟频率（$f = 1 / \Delta t$）。
5. **缩放至窗口**：点击 **缩放至窗口**，即可将选定的时间区间放大铺满 100% 画布宽度。

## Delta 周期 (\(\delta\)) 与毛刺竞争检测

传统仿真器会将零时间事件折叠压缩为单一时间戳，从而掩盖了组合逻辑竞争冒险。Axiom 提供了显式的 delta 周期透视分析：
- **步进 Delta (`F11`)**：步进单个离散零时间 delta 周期 (δ周期)（$\delta \to \delta + 1$）。
- **毛刺隐患标记**：当信号在同一个物理时间戳 ($t_0$) 内发生多次跳变时，波形画布会以琥珀色警告旗标醒目标注该网线。
- **Delta 周期横向展开视图**：在水平方向上展开零时间区间，完整展现电路在达到稳态前内部级联产生的各门级中间跃变过程。

## IEEE 1364 VCD 导出与差分比对

- **导出 VCD**：将当前 4态逻辑空间 / Value Change Dump (VCD) 仿真历史导出为标准文件（`.vcd`），直接兼容 GTKWave、ModelSim 或 Vivado。
- **导入 VCD (`ImportVcdModal`)**：将外部生成的 VCD 波形文件直接加载载入 Axiom。
- **波形差分对比**：自动将当前仿真波形与参考黄金标准 VCD 文件进行比对，逐周期以错误旗标高亮标示信号不匹配处。
