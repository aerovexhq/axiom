# 虚拟硬件实验台与开发板仿真

Axiom 虚拟硬件实验台架起了 HDL 仿真与物理硬件测试之间的桥梁。它提供高度仿真的数字面包板模拟，使高校学生与 FPGA 工程师能够通过触感开关、按键、LED 和七段数码管与自己的硬件设计进行实时交互。

---

## Digilent Basys 3 FPGA 开发板实验舱

Basys 3 FPGA 实验舱提供了 Digilent 广受好评的 Artix-7 开发板的高精度数字孪生：

```
+-------------------------------------------------------------------------------+
| Axiom Basys 3 Artix-7 Hardware Emulation Bay                                  |
+-------------------------------------------------------------------------------+
| [SSEG Display:  1 0 4 2 ]       [BTNU]                 [LD15 .. LD0]          |
| Anode: AN3..AN0 Active        [BTNL] [BTNC] [BTNR]     * * * * * * * *        |
| Segments: CA..CG, DP            [BTND]                 O O O O O O O O        |
|                                                                               |
| Tactile Slide Switches:                                                       |
| [SW15] [SW14] [SW13] [SW12] [SW11] [SW10] [SW9] [SW8] ... [SW1] [SW0]         |
|  [ON]   [OFF]  [OFF]  [ON]   [ON]   [OFF]  [OFF] [ON]       [OFF] [ON]        |
+-------------------------------------------------------------------------------+
```

### 1. 16 个触觉拨码开关 (`SW0`..`SW15`)
- 通过 XDC 物理管脚约束直接映射至输入端口（`PACKAGE_PIN V17` 等）。
- 交互式点击可切换开关位置，并伴随逼真的机械音效与状态持久化保存。
- 高对比度拨动操作杆，配有清晰直观的绿色状态指示点。

### 2. 16 个贴片式 LED 指示灯 (`LD0`..`LD15`)
- 通过 XDC 约束直接映射至输出端口（`PACKAGE_PIN U16` 等）。
- 逼真的翠绿色辉光渲染效果，指示活动的逻辑高电平状态 (`1`)。

### 3. 5 个瞬态轻触按键 (`BTNC`, `BTNU`, `BTNL`, `BTNR`, `BTND`)
- 采用居中、上、左、右、下的标准十字方向按键布局配置。
- 按下时保持逻辑高电平 (`1`)，松开时恢复为逻辑低电平 (`0`)。非常适合手动复位选通或单步时钟输入。

### 4. 4 位动态扫描复用七段数码管 (`SSEG`)
- 忠实实现阴极/阳极动态时分复用扫描机制。
- 精确渲染由低电平有效的位选阳极信号线 (`AN0` 到 `AN3`) 控制的各段位 (`CA` 到 `CG`) 与小数点 (`DP`)。

## 基础组合逻辑实验舱

专为基础数字逻辑教学与真值表验证而设计，组合逻辑实验舱提供了专属的触觉交互界面：
- **交互式输入**：三个醒目的拨动开关（`A`、`B`、`C`）。
- **门级探针**：用于中间内部线网（`w1`、`w2`、`w3`、`w4`）的实时信号电压指示引脚。
- **输出 LED**：醒目的指示发光二极管，显示电路最终输出 `F`。
- **同步 8 行真值表 HUD**：完整展示所有 $2^3 = 8$ 种输入组合（$000$ 至 $111$）。根据当前开关状态动态点亮活动行，为布尔逻辑的正确性提供即时直观的视觉确认。

## 自动化实验评分系统 (`LabGraderModal`)

与多所大学数字设计课程（包括伊斯坦布尔大学 - 杰拉赫帕夏）深度合作联合打造：
- **自动化验证**：针对学生编写的 RTL 实现代码 (`uygulama_0.v`) 自动执行完整的测试激励向量矩阵。
- **综合评分卡**：自动计算百分制得分、时序精准度以及功能覆盖率。
- **测试向量矩阵**：详细比对每个仿真测试步长下的预期输出与实际输出信号。
- **Markdown 评分报告导出**：一键生成格式规范的实验提交报告，便于教师快速查阅审阅。
