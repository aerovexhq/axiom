# 交互式 IEEE 门级原理图 DAG 可视化分析器

Axiom EDA 原理图可视化分析器将解析后的 Verilog 网表转换为基于 HTML5 Canvas 加速渲染的高性能交互式有向无环图 (DAG)。它为组合逻辑锥、触发器、算术宏单元以及总线路由提供精确到周期的门级透视能力。

---

## Vivado 级无碰撞正交通道布线

传统的 EDA 可视化工具往往生成错综复杂、难以追踪的乱线网。Axiom 引入了先进的正交通道布线算法：

```
+-------+                                     +-------+
| In A  |--------[ Straight Track ]---------> | In 0  |
+-------+                                     | AND1  |
                                       +----> | In 1  |
+-------+       +--------+             |      +---+---+
| In B  |------>|  INV1  |-------------+          |
+-------+       +--------+                        V
                                              [ Out F ]
```

### 1. 网格数据通路行对齐
输入端口、逻辑门和输出引脚被划分为逻辑数据通路层 ($L_0, L_1, \dots, L_n$)。相连引脚在数学上沿同一水平轴线对齐 ($Y_{\text{out}} = Y_{\text{in}}$)，使关键走线以 **零拐角** 的纯水平直线进行渲染。

### 2. 跨层目标步进布线
当连线跨越多层 ($dx \ge 150\text{px}$) 时，连接先保持其源端的水平轨迹，并在紧邻目标引脚前方的专用开放通道 ($dstX - 28$) 中执行垂直折角。

### 3. 文本防遮挡遮蔽垫板
每个门实例标签（`inv1`、`and1`、`or1`）和引脚标识符都渲染在坚固的背景保护垫板 (`#0c1017`) 之上，彻底杜绝了网线重叠遮挡或穿过文本标注的问题。

### 4. 障碍感知的通道绕行
布线引擎 (`routeOrthogonalEdge`) 在中间逻辑门周围动态维护安全间距包围盒 (`KeepOutBox`)，引导连线干净利落地经由开放的垂直通道绕行。

## 画布交互导航与动态居中定位

- **无限平移**：在画布任意空白区域单击并拖拽，即可在大规模复杂网表间自如平移。
- **平滑滚轮缩放**：滑动触控板或鼠标滚轮，即可在 10% 至 500% 之间实现无级平滑缩放。
- **动态中心点摄像机锚定**：在拖动中央可调节分割栏时，Axiom 的 `ResizeObserver` 在数学上将世界坐标系中的摄像机中心点严格锁定在可视化窗格正中心：
  $$\Delta \text{offsetX} = \frac{\Delta W}{2}, \quad \Delta \text{offsetY} = \frac{\Delta H}{2}$$
  这使得原理图始终保持完美居中与稳定，绝不会出现水平挤压形变或缩放突跳现象。

## 实时信号探针与抬头显示 (HUD)

悬停或点击任何连线或逻辑门，可获得即时的硬件内省诊断：
- **网线探针**：显示线网名称、位宽以及实时 4态逻辑值（`0`、`1`、`X`、`Z`）。
- **光标跟随悬停卡片**：伴随指针平滑移动，并通过视口边界约束算法确保信息始终完整展示在视口内。
- **逻辑门真值表 HUD**：点击任何组合逻辑门（AND、OR、XOR、INV、MUX）会显示悬浮真值表，高亮标出当前的输入向量以及计算得到的输出状态。
- **逻辑锥高亮展示**：选中任意网线将以荧光青色整体点亮其上游所有扇入逻辑锥以及下游扇出目标。
