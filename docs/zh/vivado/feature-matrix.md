# Vivado 对比 Axiom 特性对比矩阵

传统 AMD Vivado 仿真环境与下一代 Axiom EDA 引擎之间的详尽技术对比。

---

## 技术能力对比

| 技术特性 | AMD Vivado 设计套件 | Axiom EDA (Aerovex) |
| :--- | :--- | :--- |
| **主执行引擎** | 磁盘编译的 `xsimk` 快照 | 内存中 Cranelift JIT 编译原生机器码 |
| **典型编译耗时** | 30 – 120 秒 | **1 – 3 毫秒** |
| **仿真吞吐量** | 10 万 – 25 万事件/秒 | **78 万+ 事件/秒** |
| **Delta 周期控制** | 黑盒不透明（压缩折叠 delta 步长） | **调用方控制的 `step_delta`** |
| **毛刺 / 冒险追踪** | 隐藏不显示 | **静态与动态冒险精确检测** |
| **芯片功耗建模** | 仿真后静态估算 | **实时物理动态 $P = \frac{1}{2} C V^2 f \alpha$** |
| **PDN 电压骤降** | 需要外部 SPICE 仿真建模 | **内置电感性 PDN 电压骤降 (IR + L di/dt) 建模** |
| **内存状态管理空间** | 碎片化的 C++ 结构体 | **连续 64 位双向量 4态逻辑空间** |
| **波形导出格式** | 专有 `.wdb` + `.vcd` | **标准 IEEE 1364 Value Change Dump (VCD)** |
| **功耗数据导出** | 生成 SAIF | **标准 SAIF 2.0 完全互操作** |
| **GUI 界面框架** | Java Swing（庞大沉重，受内存限制） | **Tauri v2 + React 19（黑曜石深色风格）** |
| **网页浏览器内执行** | 不可能实现 | **100% 纯客户端 WebAssembly** |
| **安装体积占用** | 60 – 110 GB | **< 50 MB** |
| **macOS 原生支持** | 否（必须通过 Linux 虚拟机） | **原生支持 Apple Silicon (AArch64)** |
| **许可证成本** | 高昂的单机/浮动节点许可费用 | **开源内核 (MIT 许可证)** |
