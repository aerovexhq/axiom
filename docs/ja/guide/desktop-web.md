# デスクトップ＆Webアーキテクチャ

Axiomは統合されたデュアルターゲットアーキテクチャを採用しています。軽量なネイティブデスクトップアプリケーションと、インストール不要で100%ブラウザ内で動作するWebAssemblyエンジニアリングダッシュボードです。

---

## デュアルターゲットの概要

```
                        Axiom Core Architecture
                                   |
                  +----------------+----------------+
                  |                                 |
                  v                                 v
        Native Desktop Target                WebAssembly Target
        - Tauri v2 (Rust IPC)               - wasm32-unknown-unknown
        - Linux, macOS, Windows             - 100% Client-Side In-Browser
        - Direct Cranelift JIT in RAM       - Portable Evaluator in WebWorker
        - Sub-50 MB Binary                  - Zero Backend Server Dependencies
```

## モダンなObsidianダークテーマUI

エンジニアリングフロントエンドは、**React 19**、**TypeScript 5.7**、**PostCSS**、**Vite 6**で構築されており、ObsidianやLinearに着想を得たダークワークスペースを提供します:

1. **シミュレーション制御ヘッダー**:
   - 個別ステッピング制御: `Run Free`、`Pause`、`+1 ns`、`+100 ps`、`Step δ`（ゼロ時間デルタサイクル (δサイクル)）。
   - ライブテレメトリ表示: シミュレーションタイムスタンプ（$ps / ns$）、アクティブデルタサイクル（$\delta$）、ピーク過渡電流（$mA$）、最大電圧降下（$mV$）。
2. **エラボレート済みネットリスト階層エクスプローラ**:
   - エラボレートされたスコープ、モジュールインスタンス、レジスタ、ワイヤ、プロシージャルプロセスの再帰的ツリービュー。
   - 内蔵フィクスチャ切り替え（ALU、グリッチ付きカウンタ、階層型コア）。
3. **高性能Canvas 2D波形ビューア**:
   - 仮想化された60+ FPSデジタル論理レンダリング。
   - 識別しやすい4値論理カラー: 0（スレート）、1（エメラルド）、X（ローズ）、Z（アンバー）。
   - 中央に16進数値を配したマルチビットバスのダイヤモンド遷移エンベロープ。
   - **デルタグリッチ拡大鏡**: ピンクのバグフラグで過渡的なゼロ時間ハザードを強調表示。
4. **物理シリコンテレメトリチャート**:
   - シアングラデーションで塗りつぶされたアナログ過渡電流曲線（$I(t)$）。
   - 電源レールのインダクティブPDN電圧降下 (IR + L di/dt)（$V_{sag} = IR + L \frac{di}{dt}$）。
   - 動的サマリーカード: 平均電力（$mW$）、ピーク電流（$mA$）、最大電圧降下（$mV$）、総消費エネルギー（$nJ$）。
5. **シミュレーションカーネルコンソール＆エクスポータ**:
   - リアルタイムイベントログストリーム。
   - IEEE 1364 4値論理 / Value Change Dump (VCD)（`.vcd`）およびSynopsys `.saif` ファイルのワンクリックダウンロード。
