# 導入＆プロジェクトマニフェスト

## Axiom EDAの使命

**Axiom** は、AMD Vivadoのハードウェア記述言語（HDL）処理・シミュレーション・解析エンジンをゼロから再設計し、近代化した高性能クロスプラットフォームエンジンであり、**Aerovex** のもと **Rust** でネイティブ構築されています。

VivadoはFPGA開発における業界標準ですが、何十年にも及ぶ技術的肥大化に悩まされています:
- **100GB以上のインストールサイズ**: 複雑なライセンスデーモンと長時間のセットアップが必要です。
- **重いJava Swingインターフェース**: ギガバイト単位のメモリを消費し、波形描画中にフリーズします。
- **複数段階のファイルベースコンパイルパイプライン**: 軽微なHDL修正であっても数分を要します（`xvlog` $\to$ ライブラリDB $\to$ `xelab` $\to$ スナップショットバイナリ $\to$ `xsim`）。
- **モダンなプラットフォームへの完全な非対応**: macOS（Apple Silicon M1/M2/M3/M4）や標準Webブラウザをサポートしていません。
- **不透明なゼロ時間デルタサイクル**: 一時的な組み合わせ回路の競合状態やグリッチが設計者から隠蔽されます。

**Axiomはこれらの限界を解体します。** 50MB未満で瞬時に動作し、深層まで内省可能なハードウェアシミュレーションエンジンを、Obsidianに着想を得たデスクトップおよびWebアプリケーションとともに提供します。

## 中核アーキテクチャの柱

### 1. インメモリCranelift JITコンパイル
Axiomは中間C++ファイルの出力、外部GCC/Clangの呼び出し、スナップショットのシリアライズを完全に排除します。エラボレートされたハードウェアネットリストとプロシージャルプロセスは、**Cranelift**（x86_64、AArch64）を使用してメモリ内でネイティブ機械語に直接3ミリ秒未満でコンパイルされます。

### 2. 手動デルタ時間ティック＆イベントキューAPI
シミュレーション時間を無条件に進めたり、デルタサイクルを単一のタイムスタンプに集約したりする従来のシミュレータとは異なり、Axiomは呼び出し側で制御可能なステッピングAPIを提供します:
- `engine.tick(delta_time)`: ピコ秒またはナノ秒単位で物理時間を進めます。
- `engine.step_delta()`: ゼロシミュレーション時間内で単一の離散ゼロ時間デルタサイクル (δサイクル)（$\delta \to \delta + 1$）を進め、信号が整定する前の過渡的なハザードを露出させます。

### 3. 物理ベースの電圧・エネルギー・電力テレメトリ
Axiomは、すべての信号遷移に第一原理の物理方程式を組み込んでいます:
- **動的電力**: $P_{\text{dynamic}} = \frac{1}{2} C_{\text{net}} V_{\text{dd}}^2 f \alpha$
- **インダクティブPDN電圧降下 (IR + L di/dt)**: $V_{\text{sag}} = IR + L \frac{di}{dt}$
- Vivadoの静的見積もりレポートでは検出できないクロックエッジ時の微小電流スパイクを捉えます。

### 4. クロスプラットフォーム対応デスクトップ＆Webアーキテクチャ
**Tauri v2**、**React 19**、**TypeScript**、**Vite**で構築されたAxiomは、Linux、macOS、Windows上でネイティブデスクトップアプリとして動作する一方、**WebAssembly**（`wasm32-unknown-unknown`）にシームレスにコンパイルされ、100%ブラウザ内でのシミュレーションを実現します。
