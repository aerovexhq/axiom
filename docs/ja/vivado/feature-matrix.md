# Vivado vs. Axiom 機能比較マトリックス

レガシーなAMD Vivadoシミュレーション環境と次世代Axiom EDAエンジンとの詳細な機能比較です。

---

## 技術仕様比較

| 機能 / 項目 | AMD Vivado Design Suite | Axiom EDA (Aerovex) |
| :--- | :--- | :--- |
| **主実行エンジン** | ディスクコンパイルされた `xsimk` スナップショット | メモリ内直接Cranelift JIT機械語 |
| **典型的なコンパイルレイテンシ** | 30 〜 120秒 | **1 〜 3ミリ秒** |
| **シミュレーションスループット** | 100k 〜 250k イベント/秒 | **780k+ イベント/秒** |
| **デルタサイクル制御** | 不透明（デルタステップを集約） | **呼び出し元制御の `step_delta`** |
| **グリッチ / ハザード追跡** | 非表示（不可視） | **静的および動的ハザード検出** |
| **シリコン消費電力モデリング** | シミュレーション後の静的見積もり | **リアルタイム動的 $P = \frac{1}{2} C V^2 f \alpha$** |
| **PDN電圧降下** | 外部SPICEモデリングが必要 | **組み込みインダクティブPDN電圧降下 (IR + L di/dt) モデル** |
| **メモリ状態アリーナ** | 断片化されたC++構造体 | **連続64ビットデュアルベクター** |
| **波形エクスポータ** | 独自 `.wdb` + `.vcd` | **標準 IEEE 1364 4値論理 / Value Change Dump (VCD) (`.vcd`)** |
| **電力エクスポータ** | SAIF生成 | **標準SAIF 2.0相互運用性** |
| **GUIフレームワーク** | Java Swing（動作が重く、メモリ消費大） | **Tauri v2 + React 19（Obsidianダーク）** |
| **Webブラウザ実行** | 不可 | **100% クライアントサイドWebAssembly** |
| **インストールサイズ** | 60 〜 110 GB | **50 MB 未満** |
| **macOSネイティブサポート** | 非対応（Linux仮想マシンが必要） | **Apple Silicon（AArch64）ネイティブ対応** |
| **ライセンスコスト** | 高額なモノリシックシートライセンス ($$$) | **オープンソースコア（MITライセンス）** |
