# 4値論理ステートアリーナ

ハードウェア記述言語は、完全なIEEE 1800 4値論理セマンティクスを要求します:
- `0`: 強力なLow論理レベル。
- `1`: 強力なHigh論理レベル。
- `X`: 不定または未初期化論理レベル（ハザードまたは競合）。
- `Z`: 高インピーダンス（トライステートのフローティングネット）。

8ビットまたは32ビットのenumで論理状態を単純に表現すると、キャッシュの局所性が損なわれ、ビット並列SIMD演算が不可能になります。

---

## デュアルベクタービット並列エンコーディング

Axiomは、デュアルワードビット表現を使用して、すべての回路ネットを連続したメモリアリーナ（`SimStateArena`）に配置します:

| 論理値 | `value` ビット | `mask` ビット | 説明 |
| :--- | :---: | :---: | :--- |
| **`0`** | `0` | `0` | 確定Low論理レベル |
| **`1`** | `1` | `0` | 確定High論理レベル |
| **`X`** | `0` | `1` | 不定値 / 未初期化状態 (X) |
| **`Z`** | `1` | `1` | 高インピーダンス / 切断状態 (Z) |

### メモリレイアウト
- `values: Box<[u64]>` および `masks: Box<[u64]>` 用の連続した64ビットアライメント済みメモリブロック。
- 32ビットネットは両方のベクターでオフセット $i$ を占有します。
- ネットの読み取りまたは書き込みには、$O(1)$ のポインタオフセット参照のみを必要とします。

### ビット単位の論理演算
デュアルベクターを使用することで、4値ブール演算が64ビットすべてにわたって同時に並列実行されます:

```rust
// 4-State Bitwise AND:
// result_val  = val_a & val_b
// result_mask = (mask_a & (val_b | mask_b)) | (mask_b & (val_a | mask_a))

let res_val = val_a & val_b;
let res_mask = (mask_a & (val_b | mask_b)) | (mask_b & (val_a | mask_a));
```
これにより、ホストCPUのクロックサイクルあたり数千のビット演算を実行することが可能になります。
