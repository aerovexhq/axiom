# シミュレーションコマンドリボン＆統合ドック

Axiomシミュレーション制御システムは、高速実行エンジンと直感的なコマンドリボンおよび統合ボトムドック（`BottomConsole.tsx`, `UnifiedBottomDock.tsx`）を組み合わせています。物理シミュレーション時間と離散ゼロ時間デルタサイクル (δサイクル) を即座に制御できます。

---

## ヘッダーシミュレーションコマンドリボン

トップヘッダーバーにはシミュレーションテレメトリと制御が表示されます:

```
+-------------------------------------------------------------------------------+
| [ Run ] [ Pause ] | [ +1 ns ] [ +100 ps ] [ Step Delta ] | [ Reset (t=0) ]    |
| Time: 125,400 ps (125.4 ns) | Delta: 0 | Core: 0.988 V | Power: 34.2 mW       |
+-------------------------------------------------------------------------------+
```

### 制御アクション
- **実行 (`Space` / `Ctrl + Enter`)**: バックグラウンドWeb WorkerまたはCranelift JITエンジン内で高周波数の自律的クロック進行を開始します。
- **一時停止 (`Space`)**: シミュレーション実行を即座に中断し、検査のためにすべての信号トレースとレジスタ状態を静止させます。
- **+1 ns (`F10`)**: 物理シミュレーション時間を正確に1,000ピコ秒進めます。
- **+100 ps (`Shift + F10`)**: 微細なタイミング解析のために、物理シミュレーション時間を正確に100ピコ秒進めます。
- **ステップデルタ (`F11`)**: 物理シミュレーション時間を進めることなく単一の離散ゼロ時間評価サイクル（$\delta \to \delta + 1$）を進め、組み合わせ回路の競合状態や中間ゲート遷移を露出させます。
- **リセット (`Ctrl + R`)**: シミュレーション時間を $t=0$ に巻き戻し、信号ベクトルを初期状態にリセットし、再エラボレーションなしで即座に実行を再開できるよう設計のコンパイル状態を維持します。

## 統合ボトムドックタブ

折りたたみ式ドックには重要なセカンダリエンジニアリングツールが整理されています:

### 1. コンソール＆REPL
- コンパイラパス、ASTエラボレーション指標、アクティブなモジュールインスタンスを表示します。
- Verilogシミュレーションからのリアルタイムな `$display`、`$write`、`$monitor` 出力をストリーミングします。
- 信号式の評価やネット値のクエリを行う対話型コマンドプロンプトを提供します。

### 2. 問題＆リンター
- アクティブな静的解析警告および構文エラーをリスト表示します。
- ルールID（`AXIOM_W001` など）、重大度バッジ、ソースファイル名を表示します。
- 任意の問題カードをクリックすると、Monacoエディタ内の該当する行に即座に移動します。

### 3. テレメトリレーダー
- コア電圧、インダクティブ電圧降下、供給電流、動的消費電力のリアルタイムアナログメーターを表示します。

### 4. 波形ドック
- プライマリビジュアライザペインが回路図、バーチャルラボ、またはタイミングレーダーにフォーカスされている間、補助的な波形プレビューを描画します。
