# 高密度波形＆ロジックアナライザ

Axiom EDAは、高速化されたHTML5 Canvas上にレンダリングされる高密度60+ FPSデジタル波形ビューアおよびロジックアナライザを備えています。エンジニアは複数信号のタイミング関係の検査、バス基数の展開、時間間隔の測定、ゼロ時間デルタサイクルのグリッチ検出を行うことができます。

---

## 階層化デジタルタイムライン

波形ビューアは仮想化された垂直スクロールでデジタルトレースを描画し、数百の信号をUIラグなしで収容します:

```
Signal Name   Radix   | 0 ns      5 ns      10 ns     15 ns     20 ns     25 ns
----------------------+--------------------------------------------------------
clk           1-bit   | _/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_/\_
rst_n         1-bit   | _____/=================================================
data_in[7:0]  Hex     | = 00 =X= 41 =X= 42 =X= 43 =X= 44 =X= 45 =X= 46 ======
valid_in      1-bit   | ______/===========\___________/=======================
busy_out      1-bit   | ____________/===========\___________/=================
----------------------+--------------------------------------------------------
                      |       |<---- Delta-T: 10.0 ns (100.0 MHz) ---->|
```

### 信号表示機能
- **基数の切り替え**: 任意の信号の基数バッジを右クリックまたはクリックして、**16進数**、**2進数**、**符号なし10進数**、**符号付き10進数**、**ASCII** を切り替えます。
- **バスの展開**: マルチビットベクター（`data[7:0]`）の横にある山形記号（`>`）をクリックして、個々のビットラインを展開します。
- **カラーハイライト**: トレースは論理レベルを鮮明なシアン、バスをアンバー、不定/競合状態（`X`, `Z`）を赤で高コントラストに描画します。

## ドラッグ計測ウィンドウ

Axiomは、時代遅れの2カーソル計測ワークフローを直感的なドラッグ計測ウィンドウに刷新しました:

1. **クリック＆ドラッグ**: 波形タイムライン上の任意の領域をドラッグして計測ウィンドウをハイライトします。
2. **境界ハンドル ($[A, B]$)**: 左右の境界ハンドルをドラッグして、ピコ秒精度で計測終点を微調整します。
3. **スライディングウィンドウ**: 計測ウィンドウの中央をドラッグして、タイムラインに沿って時間間隔全体をスライドさせます。
4. **ライブ計測HUD**: HUDには以下が表示されます:
   - **時刻 A ($T_A$)**: 簡潔な工学単位（ps, ns, us, ms）付きの開始タイムスタンプ。
   - **時刻 B ($T_B$)**: 終了タイムスタンプ。
   - **デルタ時間 ($\Delta t$)**: 正確な継続時間（$\Delta t = |T_B - T_A|$）。
   - **周波数 ($f$)**: 等価クロック周波数（$f = 1 / \Delta t$）。
5. **ウィンドウにズーム**: **ウィンドウにズーム** をクリックすると、選択した時間間隔がキャンバス幅100%に拡大されます。

## デルタサイクル (\(\delta\))＆グリッチ検出

従来のシミュレータはゼロ時間イベントを単一のタイムスタンプに集約し、組み合わせ回路の競合状態を隠してしまいます。Axiomは明示的なデルタ検査を提供します:
- **ステップデルタ (`F11`)**: 単一の離散ゼロ時間評価サイクル（$\delta \to \delta + 1$）を進めます。
- **グリッチハザードマーカー**: 同一の物理タイムスタンプ（$t_0$）内で信号が複数回遷移した場合、波形キャンバスは該当ネットをアンバーの警告フラグで強調表示します。
- **デルタ展開ビュー**: ゼロ時間インターバルを水平方向に展開し、回路が定常状態に達する前の中間ゲート遷移のカスケードを明らかにします。

## IEEE 1364 4値論理 / Value Change Dump (VCD) エクスポート＆インポート比較

- **VCDエクスポート**: 現在のシミュレーション履歴をGTKWave、ModelSim、Vivadoと直接互換性のあるIEEE 1364 4値論理 / Value Change Dump (VCD)（`.vcd`）としてエクスポートします。
- **VCDインポート (`ImportVcdModal`)**: 外部のVCDファイルをAxiomに読み込みます。
- **波形差分比較**: シミュレーション波形トレースをゴールデン参照VCDファイルと自動比較し、信号の不一致をサイクル単位のエラーフラグで強調表示します。
