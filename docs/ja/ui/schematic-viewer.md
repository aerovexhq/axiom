# インタラクティブIEEEゲートDAG回路図ビジュアライザ

Axiom EDAの回路図ビジュアライザは、パースされたVerilogネットリストを、アクセラレーション対応HTML5 Canvas上にレンダリングされる対話型高性能有向非巡回グラフ（DAG）に変換します。組み合わせ論理コーン、フリップフロップ、演算マクロ、バス経路に対するサイクル精度・ゲートレベルの可視性を提供します。

---

## Vivado品質の衝突フリー配線ルーティング

従来のEDAビジュアライザは、追跡が困難な交差したスパゲッティ配線を生成しがちでした。Axiomは高度な直交チャネルルーティングアルゴリズムを採用しています:

```
+-------+                                     +-------+
| In A  |--------[ Straight Track ]---------> | In 0  |
+-------+                                     | AND1  |
                                       +----> | In 1  |
+-------+       +--------+             |      +---+---+
| In B  |------>|  INV1  |-------------+          |
+-------+       +--------+                        V
                                              [ Out F ]
```

### 1. グリッドデータパス行アライメント
入力ポート、論理ゲート、出力ピンは論理データパス層（$L_0, L_1, \dots, L_n$）に分割されます。接続されたピンは同一の垂直行に沿って数学的に整列され（$Y_{\text{out}} = Y_{\text{in}}$）、主要な接続が**方向転換ゼロ**の直線水平ラインとして描画されます。

### 2. 多層デスティネーションステッピング
配線が複数の層を跨ぐ場合（$dx \ge 150\text{px}$）、接続は始点の水平トラックを維持し、デスティネーションピン直前の専用オープンチャネル（$dstX - 28$）で垂直方向の段差を実行します。

### 3. テキスト保護ノックアウトプレート
すべてのゲートインスタンスラベル（`inv1`, `and1`, `or1`）およびピン識別子は、ソリッドな背景保護ノックアウトプレート（`#0c1017`）の上に描画されます。これにより、配線が文字注記と重なったり横切ったりすることが完全に防止されます。

### 4. 障害物検知チャネル迂回
ルーティングエンジン（`routeOrthogonalEdge`）は、中間ゲートの周囲にクリアランス境界ボックス（`KeepOutBox`）を動的に維持し、開放された垂直チャネルを通して配線をきれいに迂回させます。

## キャンバスナビゲーション＆動的センタリング

- **無限パン**: キャンバスの空いている領域をクリック＆ドラッグして、大規模なネットリストを自由に移動できます。
- **スムーズホイールズーム**: トラックパッドまたはマウスホイールをスクロールして、10%から500%の間で連続的にズームできます。
- **動的カメラ中点アンカリング**: 中央のリサイズ可能スプリッターをドラッグすると、Axiomの `ResizeObserver` がワールド空間のカメラ中点をビジュアライザペインの中心に数学的にロックします:
  $$\Delta \text{offsetX} = \frac{\Delta W}{2}, \quad \Delta \text{offsetY} = \frac{\Delta H}{2}$$
  これにより、水平方向の押しつぶれやズームの乱れが発生することなく、回路図が完全に中央に安定して維持されます。

## ライブ信号プロービング＆HUD

配線やゲートの上にホバーまたはクリックすると、即座にハードウェアの内省情報が得られます:
- **配線プロービング**: ネット名、ビット幅、およびリアルタイム論理値（`0`, `1`, `X`, `Z`）を表示します。
- **カーソル追従ホバーカード**: 詳細情報をビューポート内に収める境界クランプ機能を備え、ポインタに追従します。
- **ゲート真理値表HUD**: 任意の組み合わせゲート（AND、OR、XOR、INV、MUX）をクリックすると、アクティブな入力ベクトルと結果の出力状態を強調表示するフローティング真理値表が表示されます。
- **論理コーンハイライト**: 任意のネットを選択すると、その上流ファンインコーン全体と下流ファンアウト先がネオンシアンで照らし出されます。
