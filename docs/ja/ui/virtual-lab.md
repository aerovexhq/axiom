# バーチャルラボラック＆ボードエミュレーション

Axiomのバーチャルラボラックは、HDLシミュレーションと物理ハードウェアテストの橋渡しをします。本格的なデジタルブレッドボードエミュレーションを提供し、学生やFPGAエンジニアがタクタイルスイッチ、プッシュボタン、LED、7セグメントディスプレイを使用してリアルタイムに回路設計と対話できるようにします。

---

## Digilent Basys 3 FPGAボードベイ

Basys 3 FPGAベイは、Digilentの人気Artix-7開発ボードの高精度なデジタルツインを提供します:

```
+-------------------------------------------------------------------------------+
| Axiom Basys 3 Artix-7 Hardware Emulation Bay                                  |
+-------------------------------------------------------------------------------+
| [SSEG Display:  1 0 4 2 ]       [BTNU]                 [LD15 .. LD0]          |
| Anode: AN3..AN0 Active        [BTNL] [BTNC] [BTNR]     * * * * * * * *        |
| Segments: CA..CG, DP            [BTND]                 O O O O O O O O        |
|                                                                               |
| Tactile Slide Switches:                                                       |
| [SW15] [SW14] [SW13] [SW12] [SW11] [SW10] [SW9] [SW8] ... [SW1] [SW0]         |
|  [ON]   [OFF]  [OFF]  [ON]   [ON]   [OFF]  [OFF] [ON]       [OFF] [ON]        |
+-------------------------------------------------------------------------------+
```

### 1. 16個のタクタイル型スライドスイッチ (`SW0`..`SW15`)
- XDC物理制約（`PACKAGE_PIN V17` など）を介して入力ポートに直接マッピングされます。
- 対話的なクリックにより、本物の効果音と状態保持を伴ってスイッチ位置が切り替わります。
- 緑のインジケータピップを備えた高コントラストな視覚的トグルレバー。

### 2. 16個の表面実装LED (`LD0`..`LD15`)
- XDC制約（`PACKAGE_PIN U16` など）を介して出力ポートにマッピングされます。
- アクティブな論理High状態（`1`）を示すリアルなエメラルドグロー描画。

### 3. 5個のモーメンタリプッシュボタン (`BTNC`, `BTNU`, `BTNL`, `BTNR`, `BTND`)
- 中央、上、左、右、下のボタン用十字方向配置。
- 押すと論理High（`1`）を保持し、離すと論理Low（`0`）に戻ります。手動リセットストローブやクロック単一ステップに最適です。

### 4. 4桁マルチプレクス7セグメントディスプレイ (`SSEG`)
- 本格的なカソード・アノード動的スキャンを実装。
- アクティブLowのアノード選択ライン（`AN0` 〜 `AN3`）によって制御されるセグメント（`CA` 〜 `CG`）および小数点（`DP`）を正確に描画します。

## 組み合わせ論理ベイ

初歩的なデジタル論理と真理値表の検証用に設計された組み合わせ論理ベイは、専用の触感インターフェースを提供します:
- **対話型入力**: 3つの目立つトグルスイッチ（`A`, `B`, `C`）。
- **ゲートプローブ**: 中間ネット（`w1`, `w2`, `w3`, `w4`）のリアルタイム信号値ピン。
- **出力LED**: 回路出力 `F` を表示する視認性の高いインジケータダイオード。
- **同期8行真理値表HUD**: 全8通り（$2^3 = 8$）の入力組み合わせ（$000$ 〜 $111$）を表示。現在のスイッチ状態に基づいてアクティブ行が動的に点灯し、ブール論理の正しさを即座に視覚確認できます。

## 自動ラボ採点機能 (`LabGraderModal`)

大学のデジタル設計カリキュラム（イスタンブール大学Cerrahpasa校など）と共同で開発:
- **自動検証**: 学生のRTL実装（`uygulama_0.v`）に対してテストベンチマトリックスを自動実行します。
- **総合採点カード**: パーセンテージスコア、タイミング精度、機能カバレッジを算出します。
- **テストベクターマトリックス**: 各シミュレーションステップにわたる期待値と実際の信号出力を詳細に比較。
- **Markdownスコアカード出力**: 指導者向けのフォーマット済み実験提出レポートをワンクリックで生成します。
