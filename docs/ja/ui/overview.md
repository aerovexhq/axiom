# Axiom Studio ワークスペース概要

Axiom Studioは、RustおよびReact 19でネイティブに開発された航空宇宙グレードのクロスプラットフォームEDAインターフェースです。応答性の高いMonaco HDLコードエディタと、同期したゲートレベル回路図、デジタル波形、触感型ハードウェアブレッドボード、静的タイミング解析 (STA)、物理シリコンフロアプランを組み合わせた統合高性能ワークスペースを提供します。

---

## ワークスペースアーキテクチャ

Axiom Studioは、レガシーEDAツールの重く断片化されたマルチウィンドウインターフェースを廃止し、統一されたデュアルペインワークスペースを採用しています:

```
+-------------------------------------------------------------------------------+
| Header: Brand | File Sets | Simulation Ribbon (Run, Step, Reset) | PDN Gauges |
+---------------------------------------+---------------------------------------+
| Left Pane (Monaco HDL Editor)         | Right Pane (Dynamic Visualizers)      |
|                                       | - Schematic DAG Visualizer            |
| - Verilog / SystemVerilog / VHDL      | - Virtual Lab & Basys 3 FPGA Bay      |
| - In-RAM LSP Real-Time Linter         | - Waveforms & Logic Analyzer          |
| - Monarch Tokenizer & Autocomplete    | - Timing Radar & Static Timing        |
| - AST Hover Cards & Breadcrumbs       | - Technology Mapping Studio           |
|                                       | - Floorplanning & Silicon Die         |
|                                       | - Formal Verification (BMC)           |
|                                       | - Protocol Analyzer & Dissector       |
|                                       | - Microarchitecture & Multi-Die       |
+---------------------------------------+---------------------------------------+
| Unified Bottom Dock: Console & REPL | Problems & Linter | Telemetry Radar     |
+-------------------------------------------------------------------------------+
```

### 1. ヘッダー＆シミュレーションコマンドリボン
トップナビゲーションヘッダーには、プロジェクト識別タグ、Vivadoファイルセットセレクタ、シミュレーション実行リボンが配置されています。瞬時のコンパイル、実行、一時停止、離散ゼロ時間デルタサイクル (δサイクル) ステッピング、シミュレーション時間の巻き戻しが可能です。リアルタイム電源配線網（PDN）テレメトリメーターは、動的電力をミリワット（$P$）、インダクティブPDN電圧降下 (IR + L di/dt)（$V_{\text{sag}}$）、総供給電流（$I$）で報告します。

### 2. 左ペイン: Monaco HDLコードエディタ
AxiomのMonarch Verilog/SystemVerilogトークナイザー、ダークアクリルテーマ（`axiom-dark`）、リアルタイムASTホバーツールチップ、メモリ内言語サーバープロトコル（LSP）診断を備えたMicrosoft Monaco Editorのカスタマイズインスタンスです。

### 3. 右ペイン: ビジュアライザベイ
Axiomの視覚的解析ツールを収容する全高・全幅キャンバス:
- **回路図DAG**: 衝突のない直交チャネルルーティングを備えたリアルタイムIEEEゲートレベルネットリストビジュアライザ。
- **バーチャルラボ**: Digilent Basys 3 Artix-7ボードのスイッチ、LED、7セグメントディスプレイを備えた触感型ハードウェアブレッドボード。
- **波形**: ドラッグ計測ウィンドウとゼロ時間デルタサイクル検査を備えた60+ FPSデジタルロジックアナライザ。
- **タイミングレーダー**: クリティカルパスウォーターフォールとセットアップ/ホールドスラックヒストグラムを表示するトポロジカル静的タイミング解析 (STA)。
- **テクノロジマッピング**: RTLをターゲットFPGAプリミティブ（LUT、DSP48E2、RAMB36E2）に低レベル化するゲートレベルマッピング。
- **フロアプラン**: CLBサイト配置、熱ヒートマップ、ルーティングフライトラインを表示する2Dシリコンダイフロアプランスタジオ。
- **形式検証**: SystemVerilogアサーションのための限界モデル検査（BMC）および $k$-帰納法検証。
- **プロトコルアナライザ**: UART、SPI、I2C、CAN Bus、USB、Ethernet用のハードウェアシリアルパケット解析器。
- **マイクロアーキテクチャ**: 自動データパス検出、ALUインスペクタ、RegFileメモリビュー、FSMステートバブルグラフ。

### 4. 中央のリサイズ可能スプリッター
エディタとビジュアライザのバランスを調整できるレスポンシブな仕切りです。Axiomは動的カメラ中点アンカリングを備えており、スプリッターをドラッグするとキャンバスのワールド空間カメラ中点が継続的に再計算され、回路図の押しつぶれやズーム喪失を防ぎます。

### 5. 統合ボトムドック
セカンダリ解析ツールを整然としたタブにまとめる折りたたみ式ドック:
- **コンソール＆REPL**: 対話型Verilogコンパイラ出力、`$display` 文のログ記録、シミュレーションステータス。
- **問題＆リンター**: 構文および設計規則の警告へのワンクリック行ナビゲーションを備えたアクティブ診断カード。
- **テレメトリ**: コア電源電圧、インダクティブ降下、スイッチング電流のアナログシリコンテレメトリメーター。
- **波形プレビュー**: 分割回路図モードでの作業時に便利なコンパクトな波形表示。

## グローバルキーボードショートカット

| ショートカット | 操作 | 説明 |
| :--- | :--- | :--- |
| `Ctrl + S` / `Cmd + S` | **プロジェクト保存** | すべての設計ファイルとメタデータをディスクまたはIndexedDBに永続化 |
| `Ctrl + Enter` / `Cmd + Enter` | **コンパイル＆実行** | Cranelift JITを介してアクティブな設計をメモリにコンパイルしクロックを開始 |
| `Space` | **実行 / 一時停止** | シミュレーションエンジンの実行状態を切り替え |
| `F10` | **+1 ns ステップ** | 物理シミュレーション時間を正確に1,000ピコ秒進める |
| `Shift + F10` | **+100 ps ステップ** | 物理シミュレーション時間を正確に100ピコ秒進める |
| `F11` | **ステップデルタ (\(\delta\))** | 物理時間を進めずに単一の離散ゼロ時間デルタサイクル (δサイクル) を進める |
| `Ctrl + R` / `Cmd + R` | **シミュレーションリセット** | シミュレーションクロックを \(t=0\) に巻き戻し、初期信号ベクトルを復元 |
| `Ctrl + Alt + F` | **フロアプランスタジオ** | 物理FPGAシリコンフロアプランビジュアライザを開く |
| `Ctrl + P` / `Cmd + P` | **ファイルのクイックオープン** | オムニバー検索パレットを開きプロジェクトソース間をジャンプ |
| `Ctrl + \`` | **ボトムドックの切り替え** | 統合ボトムドックを展開または折りたたみ |
| `Ctrl + B` / `Cmd + B` | **サイドバーの切り替え** | Vivadoプロジェクトファイルセットサイドバーを表示または非表示 |
| `Escape` | **モーダルを閉じる / 選択解除** | アクティブなダイアログやインスペクタを閉じ、ネット選択をクリア |

## モバイルStudio＆レスポンシブドロワー

モバイルデバイスや狭いブラウザウィンドウ（幅 \(\le 768\text{px}\)）で動作する場合、Axiom Studioは自動的に適応します:
- 窮屈なビューポートを排除するため、複数ペインのリサイズスプリッターは無効化されます。
- オフキャンバスのスライドアウトドロワー（`MobileDrawer.tsx`）により、プロジェクトファイルセット、シミュレーション制御、ビュー選択へアクセスできます。
- インターフェースは**1画面個別表示モード**でレンダリングされ、アクティブなビューに画面幅と高さを100%割り当てます。
- 操作しやすいモバイルボトムバー（`MobileBottomBar.tsx`）が、ライブの問題バッジを備えた5つの主要ナビゲーションタブ（**コード**、**回路図**、**ラボ**、**波形**、**コンソール**）を提供します。
