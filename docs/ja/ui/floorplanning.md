# 論理合成フロアプラン＆ダイレイアウトスタジオ

Axiom EDAは、インタラクティブな2Dシリコンダイフロアプランスタジオ（`crates/ir/src/floorplan/`, `FloorplanStudioViewer.tsx`）を備えています。実際のFPGAダイレイアウト上で、物理セル配置、シリコンサイトグリッド、配線フライトライン、熱/密度ヒートマップを可視化します。

---

## FPGAシリコンダイアーキテクチャグリッド

フロアプランナーは、ターゲットFPGAアーキテクチャの正確なサイトレイアウトを描画します:

```
+-------------------------------------------------------------------------------+
| Top I/O Bank (IOB)                                                            |
+---+-----------------------------------------------------------------------+---+
| L | CLB Slice Grid (SliceL / SliceM)   | DSP Column | BRAM Column         | R |
| e | [x][x][x][ ][ ][ ][x][x][x]        | [DSP48E2]  | [RAMB36E2]          | i |
| f | [x][x][ ][ ][ ][ ][x][x][x]        | [DSP48E2]  | [RAMB36E2]          | g |
| t |------------------------------------+------------+---------------------| h |
|   | Global Clock Center Spine (BUFG / Clock Center)                       | t |
| I |------------------------------------+------------+---------------------|   |
| O | [x][x][x][x][ ][ ][ ][x][x]        | [DSP48E2]  | [RAMB36E2]          | I |
| B | [x][x][x][x][ ][ ][ ][x][x]        | [DSP48E2]  | [RAMB36E2]          | O |
+---+-----------------------------------------------------------------------+---+
| Bottom I/O Bank (IOB)                                                         |
+-------------------------------------------------------------------------------+
```

### ダイサイトタイプ
- **CLBスライス (SliceL＆SliceM)**: LUTとフリップフロップを含む論理スライス。SliceMサイトはさらに分散RAMとシフトレジスタ（SRL）をサポートします。
- **DSP列**: 高速な `DSP48E2` 演算ブロックを収容する専用マルチタイル列。
- **ブロックRAM列**: `RAMB36E2` および `RAMB18E2` 内蔵メモリ用に予約された垂直列。
- **外周入出力バンク**: パッケージピンを内部論理に接続する左・右・上・下の入出力バッファ（`IOB`）。
- **クロックスパイン**: `BUFG` とクロック配線ネットワークを収容する中央水平分配トラック。

## 解析的配置器 (HPWL)＆キャリークラスタリング

論理合成配置器は、解析的2次配置と半周囲長配線長（HPWL）最小化を使用して、すべてのセルに対して最適な $(x, y)$ 座標を計算します:
$$\text{HPWL}(e) = \max_{v \in e}(x_v) - \min_{v \in e}(x_v) + \max_{v \in e}(y_v) - \min_{v \in e}(y_v)$$

### 垂直キャリーチェーン列クラスタリング
高速キャリーチェーン（`CARRY4` / `CARRY8`）を必要とする演算マクロは、ダイ全体に任意に分散させることはできません。配置器は依存するキャリー要素を専用の高速シリコンキャリートラックに沿って連続した垂直列に自動的にクラスタ化します。

---

## シリコン密度＆熱ヒートマップ

ダイ面積は正規化された $32 \times 32$ の空間タイルマトリックスに分割されます:
- **使用率ヒートマップ**: セルは深いネイビー（空 / 低使用率）から鮮やかなアンバーおよび赤（高混雑 $>85\%$）へとシェーディングされます。
- **熱ヒートマップ**: 論理スイッチング周波数（$\alpha$）と局所密度を組み合わせて、シリコンダイ全体のサーマルホットスポットを表示します。

---

## マンハッタンフライトライン＆クリティカルパスオーバーレイ

- **ポイントツーポイントフライトライン**: 任意のセルをクリックすると、駆動されるすべてのファンアウト先を接続するマンハッタン直交配線チャネルが照らし出されます。
- **クリティカルパスネオンオーバーレイ**: 静的タイミング解析 (STA) エンジンによって特定されたワーストケースのタイミングパスが、始点フリップフロップから終点まで伸びる目立つネオンオレンジのトレースとして描画されます。
