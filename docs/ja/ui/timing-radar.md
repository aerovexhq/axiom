# 静的タイミング解析 (STA)＆タイミングレーダー

Axiom EDAは、フル機能の静的タイミング解析 (STA) エンジンと対話型タイミングレーダービジュアライザ（`crates/sta`）を組み込んでいます。論理合成可能なネットリストにわたってトポロジカルなパス伝播を実行し、ターゲットクロック制約に対するセットアップおよびホールドのスラックを計算し、物理実装前にクリティカルパスのボトルネックを特定します。

---

## 静的タイミングエンジンアーキテクチャ

STAエンジンはネットリストをタイミングノードとエッジからなる有向非巡回グラフ（DAG）に分解します:
- **タイミングノード**: ゲートピン、フリップフロップ入力（`D`, `CE`, `R`）、フリップフロップ出力（`Q`）、プライマリ入出力ポート。
- **タイミングエッジ**: セル伝播遅延（$t_{\text{logic}}$）および配線遅延（$t_{\text{route}}$）。

### タイミングスラックの定式化
ソースフリップフロップ（$FF_1$）を起点とし、デスティネーションフリップフロップ（$FF_2$）を終点とする各パスにおいて:
$$\text{Data Arrival Time} = T_{\text{clk1}} + t_{\text{cq}} + t_{\text{logic}} + t_{\text{route}}$$
$$\text{Data Required Time} = T_{\text{period}} + T_{\text{clk2}} - t_{\text{setup}} - t_{\text{skew}} - t_{\text{jitter}}$$
$$\text{Setup Slack} = \text{Data Required Time} - \text{Data Arrival Time}$$

パスは $\text{Slack} \ge 0$ のときにタイミングを満たします。負のスラック（$\text{Slack} < 0$）はタイミング違反を示し、論理の削減やパイプライン段の挿入が必要であることを意味します。

## タイミングレーダーダッシュボード

タイミングレーダービューは設計性能の総括的な概要を提示します:


### 1. タイミングKPI
- **ワースト負スラック (WNS)**: すべてのタイミング終点における最悪ケースのスラック。WNSが負の場合、設計は目標クロック周波数で動作できません。
- **総負スラック (TNS)**: 違反しているすべての終点にわたる負のスラックの合計であり、設計全体のタイミング逼迫度の深刻さを示します。
- **違反終点数**: セットアップまたはホールド要件を満たしていないレジスタまたはプライマリ出力の数。

### 2. クリティカルパスウォーターフォールテーブル
最長伝播遅延の原因となっているセル論理遷移と配線ホップの正確な物理的シーケンスを表示します。各行には要素名、増分遅延、累積到達時間、残余スラックバジェットがリストされます。

### 3. スラック分布ヒストグラム
設計全体における終点スラックの統計的広がりを視覚化します。0 nsラインの左側のビンは、最適化が必要な違反パスを強調表示します。

## クロックドメイン交差 (CDC) シンクロナイザ

静的タイミング解析 (STA) エンジンは、複数の非同期クロックドメインを持つ設計を自動的に解析します:
- 無関係なクロック間の非レジスタ接続信号横断を検出します。
- 2段および3段のフリップフロップシンクロナイザ（`cdc_sync`）を識別して検証します。
- 未制約のCDCパスを高リスクなメタスタビリティハザードとしてフラグ付けします。
