# マイクロアーキテクチャ＆マルチダイビューア

Axiom EDAは、専用のマイクロアーキテクチャ検査ツール（`crates/ir/src/microarch/`, `MicroarchViewer.tsx`, `MultiDieViewer.tsx`, `PpaParetoViewer.tsx`）を提供します。プロセッサデータパス、ALU、レジスタファイル、ステートマシン、さらにはモダンな2.5D/3Dマルチダイチップレットパッケージを自動検出します。

---

## データパスの自動検出

RTLエラボレータはモジュール構造を検査し、標準的なマイクロアーキテクチャブロックを推論します:

```
+-------------------------------------------------------------------------------+
| Microarchitecture Datapath Detector:                                          |
| Detected: 1 ALU (32-Bit) | 1 RegFile (32x32) | 1 FSM Controller (5 States)     |
+-------------------------------------------------------------------------------+
| ALU Inspector Modal:                                                          |
| - Opcode: 4'b0010 (ADD) | Operand A: 0x0000_0020 | Operand B: 0x0000_0014     |
| - Result: 0x0000_0034   | Zero Flag: 0           | Overflow: 0                |
+-------------------------------------------------------------------------------+
| FSM Bubble Diagram: [IDLE] --start--> [READ] --ready--> [EXEC] --done--> [IDLE]
+-------------------------------------------------------------------------------+
```

### 1. ALU演算インスペクタ
マルチプレクサ駆動の演算ブロックを自動検出します。アクティブなオペコード選択（ADD, SUB, AND, OR, XOR, SLL, SRL, SRA, SLT）およびリアルタイムのレジスタオペランド値を表示します。

### 2. レジスタファイル (RegFile) インスペクタ
マルチポートメモリアレイ（`reg [31:0] registers [0:31]`）を検出します。全アーキテクチャレジスタのリアルタイム16進数内容を表示するインタラクティブな32行グリッドを提供し、リアルタイムの書き込みストローブをハイライトします。

### 3. FSMステートバブルビジュアライザ (`FsmViewer.tsx`)
有限状態機械（FSM）の状態ベクトルと遷移マトリックスを自動抽出します:
- ステートバブルと遷移矢印を持つインタラクティブな有向グラフを描画します。
- ライブシミュレーション中に現在アクティブなステートバブルを点灯表示します。
- FSM構造を監査: 到達不能状態、終端トラップ状態、欠落しているデフォルト復帰分岐を検出します。

## 2.5D＆3Dマルチダイシリコンパッケージング

モダンなチップレットおよびマルチダイアーキテクチャ（AMD UltraScale+ Stacked Silicon Interconnectなど）に対応:
- **インターポーザダイレイアウト**: 複数のアクティブ論理ダイ（SLR）を接続するシリコンインターポーザを可視化します。
- **ダイ間インターコネクト (Super Long Lines - SLL)**: 物理ダイを架橋するマイクロバンプ間の帯域幅、伝播遅延、スキューを解析します。

---

## PPA パレートトレードオフエクスプローラ

PPAビューアは、3つの基本的なエンジニアリング指標にわたって設計のトレードオフを解析します:
- **消費電力 (mW)**: 総動的エネルギーおよびリークエネルギー消費。
- **性能 (MHz)**: 静的タイミング解析 (STA) から導出された最大達成可能クロック周波数。
- **面積 (LUTs / FFs)**: 総シリコンリソースフットプリント。

ビジュアライザはパレート最適な構成フロンティアをプロットし、設計者が高スループットまたは低消費電力の動作プロファイルに対して最適なパイプラインバランスを選択できるようにします。
