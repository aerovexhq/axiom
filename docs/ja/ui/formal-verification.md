# 形式プロパティ検証 (FPV) スタジオ

Axiom EDAは、エンジン内蔵の限界モデル検査器（BMC）および $k$-帰納法形式検証スイート（`crates/sim/src/formal/`, `FormalVerificationViewer.tsx`）を備えています。わかりにくいコーナーケースを見落とす可能性のある擬似ランダムテストベクターだけに頼るのではなく、形式検証はすべての可能な入力シナリオにわたってSystemVerilogアサーション（SVA）を数学的に証明または反証します。

---

## 限界モデル検査＆k-帰納法

```
+-------------------------------------------------------------------------------+
| Formal Verification Studio: Bound Depth K = 20 | Mode: k-Induction           |
| Proven: 8 | Falsified: 1 (Counterexample) | Witnessed: 4 | Inconclusive: 0    |
+-------------------------------------------------------------------------------+
| Verification Goals:                                                           |
| Status    | Goal Name           | Type   | Bound | Time (ms) | Trace          |
|-----------+---------------------+--------+-------+-----------+----------------|
| [PROVEN]  | p_fifo_no_overflow  | assert | K=20  | 14.2 ms   | -              |
| [PROVEN]  | p_fsm_legal_state   | assert | K=20  |  8.1 ms   | -              |
| [FALSIFY] | p_ack_within_4_cyc  | assert | K=12  | 24.8 ms   | [View Trace]   |
| [WITNESS] | c_fifo_full_reached | cover  | K=8   |  5.3 ms   | [View Trace]   |
+-------------------------------------------------------------------------------+
```

### 1. 限界モデル検査 (BMC)
BMCはハードウェア状態遷移関係を $k$ 個の離散クロックサイクルにわたって展開します（$s_0 \to s_1 \to \dots \to s_k$）。エンジンは到達可能な状態がアサーションに違反するかどうかを評価します。ステップ $j \le k$ で無効な状態に遭遇した場合、エンジンは正確な**反例トレース**を抽出します。

### 2. $k$-帰納法 (完全証明)
$k$-帰納法は、最初の $k$ 基本ステップでプロパティが成立し、任意の連続する $k$ ステップで成立すると仮定した場合にステップ $k+1$ でも成立することが示されれば、プロパティがすべての無限時間（$t \to \infty$）にわたって**無条件に証明**されたことになります。

## 構造的検証目標の自動生成

形式検証スタジオで設計を開くと、Axiomは手動でSVAを作成することなく、ベースラインの構造的安全プロパティを自動的に合成します:
- **`p_no_unknown_out`**: リセット解除後にプライマリ出力が高インピーダンス（`Z`）または不定値（`X`）状態に遷移しないことを証明します。
- **`p_fsm_state_valid`**: ワンホットおよびバイナリ状態レジスタが文書化されていない不正な状態ベクトルに入らないことを証明します。
- **`p_reset_stability`**: リセットラインがアサートされている間、内部レジスタが安全なリセット状態を維持することを証明します。
- **`c_fsm_active`**: 宣言されたすべてのFSM状態が到達可能であることを証明するカバープロパティを自動生成します。

## 反例スクラバー＆波形トレース注入

アサーションが失敗すると、Axiomは最小の反例トレースを生成します:
- **サイクル別スクラバー**: 障害を引き起こしたネットを示す信号差分テーブルとともに、アサーション違反に至る各サイクルをステップ実行します。
- **ワンクリック波形注入**: **波形にトレースを注入** をクリックすると、反例トレースが波形ビューアに直接ロードされ、タイムマーカーが違反サイクルに正確に配置されます。

## SVAプロパティアシスタントモーダル

形式検証スタジオには対話型SVAプロパティアシスタント（`SvaAssistantModal`）が含まれています:
- **即時アサーション**: 単純な不変アサーション（`assert (ready == 1);`）。
- **リクエスト・グラントハンドシェイク**: 応答が有界サイクル内に到着することを保証する `req |-> ##[1:4] gnt`。
- **FIFO順序付け**: 書き込まれたデータが破損することなく正確に先入れ先出し順で出力に現れることを検証。
- **ストール時の安定性**: `stall` がアサートされている間データバスが一定を維持することを保証（`stall |-> $stable(data)`）。
