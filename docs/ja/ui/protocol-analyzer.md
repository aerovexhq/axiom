# プロトコルアナライザ＆シリアルパケットインスペクタ

Axiom EDAは、組み込みのハードウェアシリアルプロトコルアナライザおよびフレーム解体エンジン（`crates/sim/src/protocol/`, `ProtocolAnalyzer.tsx`）を備えています。デジタル信号の遷移を監視し、フレーミングを抽出し、チェックサムを検証し、標準通信バスのパケットペイロードをメモリ内で直接デコードします。

---

### 1. UART (汎用非同期送受信機)
- 設定可能なボーレート（9600 〜 921600 Baud）。
- データビット: 5, 6, 7, 8, 9。
- パリティチェック: なし、偶数、奇数、マーク、スペース。
- ストップビット: 1, 1.5, 2。フレーミングエラーとブレーク条件を検出。

### 2. SPI (シリアル周辺インターフェース)
- 全二重MOSIおよびMISOの同時デコード。
- 全4つのSPIクロックモードをサポート: モード0 ($CPOL=0, CPHA=0$)、モード1 ($CPOL=0, CPHA=1$)、モード2 ($CPOL=1, CPHA=0$)、モード3 ($CPOL=1, CPHA=1$)。
- アクティブLowまたはアクティブHighのチップセレクト（`CS_N`）制御。

### 3. I2C (Inter-Integrated Circuit)
- 7ビットおよび10ビットのスレーブアドレス指定。
- START、反復START、STOPバス条件を検出。
- スレーブACK/NACKビットおよび転送方向（読み取り/書き込み）を検証。

### 4. CAN Bus 2.0A / 2.0B
- 車載グレードのコントローラエリアネットワークフレーム解体。
- ビットスタッフィングの検出と自動デスタッフ。
- 11ビット標準および29ビット拡張識別子の抽出。
- データ長コード（DLC）およびCRC-15多項式チェックサムの検証。

### 5. USB 1.1 / 2.0
- Low-Speed（1.5 Mbps）およびFull-Speed（12 Mbps）NRZIライン状態追跡。
- ビットアンスタッフィング復元。
- パケット識別子（PID）デコード: トークン（OUT, IN, SOF, SETUP）、データ（DATA0, DATA1）、ハンドシェイク（ACK, NAK, STALL）。
- CRC-5（トークン）およびCRC-16（データパケット）の検証。

### 6. Ethernet MII / RMII
- 10/100 Mbps Media Independent Interface (MII) 解析器。
- フレーム分解: プリアンブル（`0x55`）、スタートフレームデリミタ（`0xD5`）、宛先MAC、送信元MAC、EtherType。
- IPv4ヘッダー、ARP、UDPペイロードのデコード。
- フレームチェックシーケンス（FCS）CRC-32検証。

## パケットインスペクタHUD

- **トランザクションストリームテーブル**: タイムスタンプ、チャネル識別子、検証ステータスバッジ付きで順次パケット転送を表示。
- **ペイロード16進/ASCIIビューア**: フォーマットされた16進数またはクリアなASCII文字表現でバイナリペイロードを検査。
- **エラーフラグ**: 破損したパケット（チェックサム失敗、フレーミングエラー、パリティ違反）を赤色の警告バッジで強調表示。
