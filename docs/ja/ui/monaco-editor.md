# Monaco HDLコードエディタ＆言語サーバー

Axiom HDLコードエディタは、MicrosoftのMonaco Editorとメモリ内Verilog、SystemVerilog、VHDL言語サーバープロトコル（LSP）デーモン（`crates/lsp`）を統合しています。シンタックスハイライト、リアルタイム静的設計規則チェック、ASTホバーツールチップ、自動補全スニペットを組み合わせた航空宇宙グレードのIDEを提供します。

---

## Monarch HDL トークナイザー

Axiomは、IEEE 1364 Verilog、IEEE 1800 SystemVerilog、およびIEEE 1076 VHDL専用に設計されたカスタムMonarchトークナイザーを備えています。

### 視覚スタイル (`axiom-dark`)
エディタはAxiomのダークパレットでスタイリングされています:
- **キーワード** (`module`, `always_ff`, `assign`, `wire`, `reg`): 高コントラストシアン (`#00f0ff`)
- **システムタスク＆関数** (`$display`, `$finish`, `$time`, `$clog2`): バイオレット (`#a855f7`)
- **文字列**: アンバー (`#fbbf24`)
- **数値＆サイズ指定リテラル** (`8'hFF`, `1'b0`, `32'd100`): エメラルドグリーン (`#34d399`)
- **コメント** (`//`, `/* ... */`): ミュートスレート (`#64748b`)
- **識別子＆信号名**: ソフトホワイト (`#f1f5f9`)

## リアルタイムインメモリ静的リンター

構文エラーや設計ハザードの指摘に数分間のコンパイルパイプラインを必要とするレガシーツールとは異なり、Axiomのリンターは250ミリ秒のデバウンスウィンドウでメモリ内で継続的に動作します。

### 組み込み静的設計規則

| ルールID | 重大度 | 名称 | 説明と防止されるハザード |
| :--- | :--- | :--- | :--- |
| `AXIOM_W001` | 警告 | **順序ブロック内のブロッキング代入** | クロック同期ブロック（`always @(posedge clk)`）内でブロッキング代入（`=`）を使用すると、シミュレーションと論理合成の間で競合状態が発生します。 |
| `AXIOM_W002` | 警告 | **組み合わせブロック内のノンブロッキング代入** | 組み合わせブロック（`always @*`）内でノンブロッキング代入（`<=`）を使用すると、複数デルタの競合ハザードや合成不一致が発生します。 |
| `AXIOM_W003` | 警告 | **未駆動ネット** | 宣言されたワイヤやネットに継続的ドライバ（`assign`）、プリミティブ出力、サブモジュールドライバが接続されていません。 |
| `AXIOM_W004` | 警告 | **未使用信号** | 宣言されたレジスタやネットが書き込みまたは定義されていますが、下流の論理コーンで一度も読み取られていません。 |
| `AXIOM_E002` | エラー | **複数ドライバの競合** | 複数の継続的代入または同時ドライバが同一ネットを駆動し、電気的短絡と `X` 競合を引き起こします。 |
| `AXIOM_W006` | 警告 | **透過ラッチの推論** | 不完全な条件分岐（`else` のない `if`、または全条件を網羅しない `case`）により、意図しない透過ラッチが推論されます。 |
| `AXIOM_W007` | 警告 | **case文のdefault欠落** | `case` 文に `default:` 分岐が含まれておらず、未定義ベクトルで状態がトラップされる危険があります。 |
| `AXIOM_W008` | 警告 | **ビット幅の不一致** | ネットまたはポート代入の幅が左右の式で異なっており、暗黙のビット切り捨てが発生します。 |

エディタ内の違反トークンの直下に波線が表示されます。**問題＆リンター**ドック内の任意のエラーカードをクリックすると、エディタのカーソルが即座に該当の行と列にジャンプします。

## ASTホバーカード

エディタ内の識別子の上にマウスポインタを置くと、対話型のASTメタデータツールチップが開きます:
- **信号宣言**: ネット型（`wire`, `reg`, `logic`）、ビット範囲（`[31:0]`）、符号属性を表示します。
- **ドライバ位置**: 信号が代入または駆動されている正確な行番号を表示します。
- **Xilinxプリミティブドキュメント**: ハードウェアプリミティブ（`LUT6_2`, `DSP48E2`, `RAMB36E2`, `BUFG`, `CARRY8`）の上にホバーすると、完全なピン配置ドキュメント、真理値表パラメータ、動作記述が表示されます。

## 高度な自動補全

Axiomの言語サーバーは、即時の自動補全を提供します:
- **IEEE 1364/1800キーワード**: `module`、`always_ff`、`always_comb`、`case`、`generate` のスケルトン自動生成。
- **システムタスク**: `$display`、`$monitor`、`$finish`、`$dumpvars` のフォーマット済み引数テンプレート。
- **スコープ内信号**: アクティブなモジュール階層内で宣言されているネット、レジスタ、パラメータを候補表示。
- **Xilinx 7-Series / UltraScale+ プリミティブ**: ハードウェアセルの完全なポートマッピングインスタンス化テンプレート。

## エディタの操作性＆永続化

- **マルチタブファイル管理**: 複数の設計ソースを同時に開くことができます。アクティブなファイルタブはブラウザの再読み込み後も保持されます。
- **パンくずリストナビゲーション**: エディタ上部のパスバーに、現在のプロジェクト、ファイルセット、アクティブファイル、親モジュールが表示されます。
- **ビューポート位置の永続化**: Monacoエディタのスクロール位置（垂直行と水平オフセット）がファイルごとに `localStorage` にキャッシュされ、ファイルに戻った際に正確な視点が復元されます。
