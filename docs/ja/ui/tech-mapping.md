# ゲートレベルテクノロジマッピングスタジオ

Axiomのテクノロジマッピングスタジオ（`crates/ir/src/synth/`）は、動作記述RTLと物理FPGAアーキテクチャの橋渡しを行います。一般的なブール論理式、マルチプレクサ、算術演算子を、AMD/Xilinx 7-SeriesおよびUltraScale+デバイス固有のシリコンプリミティブに分解・低レベル化します。

---

## アーキテクチャ固有のプリミティブ低レベル化

```
+-------------------------------------------------------------------------------+
| RTL Verilog Code:                       | Mapped Silicon Primitives:          |
|                                         |                                     |
| assign F = (cond) ? (a + b) : (c & d);  | - LUT6_2 (INIT = 64'hE2E2_0000_...) |
|                                         | - CARRY4 (Fast Arithmetic)          |
|                                         | - FDRE   (D Flip-Flop with Enable)  |
+-------------------------------------------------------------------------------+
```

### サポートされるFPGAシリコンターゲット
エンジニアは事前設定されたハードウェアアーキテクチャから選択できます:
1. **AMD Artix-7 (XC7A35T / XC7A100T)**: 6入力LUT、CARRY4演算、DSP48E1スライス、RAMB36E1メモリ。
2. **AMD Kintex-7 (XC7K325T)**: 高速7-Seriesアーキテクチャ。
3. **AMD Zynq-7000 (XC7Z020)**: 7-Seriesプログラマブルロジックファブリックを備えたデュアルARM Cortex-A9 SoC。
4. **AMD Kintex UltraScale+ (XCKU5P)**: CARRY8チェーン、DSP48E2スライス、UltraRAMブロックを備えたモダンな16nm FinFETアーキテクチャ。
5. **Axiomバーチャルシリコン**: 教育および迅速なプロトタイピング用に最適化された汎用大容量仮想アーキテクチャ。

## ブールネットワーク分解＆K-LUTマッピング

### 1. $K$-LUT 分解
Axiomは、任意のブール論理式を $K$ 入力のルックアップテーブル（モダンなXilinx FPGAでは $K=6$）に分解します:
- 入力数が6以下のサブ関数は、単一の `LUT6` に直接マッピングされます。
- 最大5入力を共有するデュアル出力論理関数は、デュアル出力 `LUT6_2` プリミティブ（`O5`, `O6`）にマッピングされます。
- 6入力を超える論理関数（$N > 6$）は、シャノン展開を使用してカスケード接続されたLUTネットワークに分割されます。

### 2. 正確な `INIT` 16進パラメータ計算
マッピングされた各LUTは、その真理値表が64ビットの16進数 `INIT` パラメータにシリアライズされます:
$$\text{INIT}[i] = f(i_5, i_4, i_3, i_2, i_1, i_0)$$
たとえば、2入力ANDゲートは `INIT = 64'h0000_0000_0000_0008` の `LUT6` にマッピングされます。

## マクロプリミティブの推論

合成エンジンは高水準の構造的パターンを自動的に識別します:
- **DSPスライスの推論 (`DSP48E1` / `DSP48E2`)**: マルチビット乗算（`a * b`）、積和演算（`P = P + (A * B)`）、プリ加算シーケンスは、数百個の論理LUTを消費する代わりに、専用ハードウェアDSPブロックに直接マッピングされます。
- **ブロックRAMの推論 (`RAMB18E2` / `RAMB36E2`)**: 同期クロックを持つアンパックド配列（`reg [31:0] mem [0:1023]`）は、真のデュアルポートまたはシンプルデュアルポートのハードウェアブロックRAMに自動的に低レベル化されます。

## マッピング済みネットリスト検査＆構造Verilogエクスポート

テクノロジマッピングビューアの機能:
- **リソース使用率棒グラフ**: スライスLUT、スライスレジスタ（FF）、CARRYチェーン、DSPスライス、ブロックRAMの個数と使用率を表示します。
- **セルインスペクタテーブル**: マッピングされたプリミティブインスタンスを検索およびフィルタリングします。
- **真理値表HUD**: マッピングされた任意のLUTが表す正確なブール真理値表を検査します。
- **構造Verilogエクスポート**: 標準Xilinxプリミティブでインスタンス化された純粋な構造ゲートネットリスト（`.v`）をワンクリックで生成します。
