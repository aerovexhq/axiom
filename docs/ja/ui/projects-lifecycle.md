# プロジェクト＆ファイルセットライフサイクル

Axiom EDAは、軽量なWeb永続化とデスクトップファイルシステム統合を組み合わせた、本格的なVivado互換のプロジェクト管理システムを実装しています。プロジェクトは、設計RTLソース、シミュレーションテストベンチ、物理/タイミング制約の厳格な分離を維持します。

### スターターテンプレート
Axiomは、業界で実績のある7つのスターター設計図を提供しています:
1. **組み合わせ論理回路**: 9個のゲートセル（`inv1`, `inv2`, `and1`, `and2`, `or1`）と専用バーチャルラボ触感ベイを備えた、\(F = ((\neg A \land B) \land C) \lor \neg B\) を計算するゲートレベルブール論理システム。
2. **UART送受信機**: 8データビット、1ストップビット、オーバーサンプリングクロックジェネレータ、ステータスレジスタを備えた完全な送受信パイプライン。
3. **同期FIFOバッファ**: フル、エンプティ、オールモストフル、オールモストエンプティのウォーターマークフラグを備えたデュアルポインタ32x8巡回メモリバッファ。
4. **32ビットALU**: IEEE符号付き加算、減算、バレルシフト、比較、およびゼロフラグとオーバーフロー検出付きブール論理を実装した算術論理演算ユニット。
5. **SPIマスター**: プログラマブルクロック分周器を備え、モード0、1、2、3をサポートするモーター制御グレードのシリアル周辺インターフェース。
6. **FSM信号制御機**: 青、黄、赤の遷移シーケンス、歩行者リクエストラッチ、タイマーカウンタを備えた4方向交差点の有限状態機械。
7. **IUC Cerrahpasaデジタル論理実験**: `uygulama_0.v`、自動テストベンチ、Basys 3 Artix-7制約を備えたイスタンブール大学Cerrahpasa校の授業用プロジェクト。

## Vivadoファイルセット構造

Axiomはプロジェクトファイルを標準のVivadoファイルセットカテゴリに整理します:

```
project_root/
|-- sources_1/           # Design Sources
|   |-- logic_circuit.v  # Primary RTL implementation [TOP]
|   `-- uart_tx.v        # Submodules
|-- sim_1/               # Simulation Sources
|   `-- tb_circuit.v     # Testbench harness
`-- constrs_1/           # Physical & Timing Constraints
    `-- timing.xdc       # XDC pinouts and clock declarations
```

### 1. 設計ソース (`sources_1`)
Verilog、SystemVerilog、またはVHDLで実装されたすべての論理合成可能ハードウェアモジュールを含みます。
- **最上位モジュール指定 (`[TOP]`)**: 論理合成、回路図生成、物理フロアプラン用のアクティブなルートモジュール。ファイルカード上の3点ドットメニューから任意のモジュールをトップに指定できます。
- **ソース追加 (`+`) アクション**: 設計ソースヘッダーの `+` ボタンをクリックすると、`sources_1` カテゴリがあらかじめ選択された状態で `AddSourceModal` が開きます。

### 2. シミュレーションソース (`sim_1`)
テストベンチハーネス（`tb_*.v`）、刺激ベクトル、検証シーケンスを含みます。テストベンチファイルは物理合成やテクノロジマッピングから除外され、誤った複数ドライバや未制約ピンの警告を防止します。

### 3. 制約 (`constrs_1`)
FPGAパッケージピン割り当て（`PACKAGE_PIN`, `IOSTANDARD`）および静的タイミング解析 (STA) クロック目標（`create_clock`）を定義するXilinx設計制約（`.xdc`）ファイルを含みます。

## プロジェクトヘッダーメニュー (`ProjectDropdown`)

左上のプロジェクトドロップダウンバッジから、主要なライフサイクル操作に直接アクセスできます:
- **プロジェクト保存 (`Ctrl + S`)**: 即座の視覚的確認とともに、すべてのエディタバッファをディスク（デスクトップ）またはIndexedDB（Web）に書き出します。
- **プロジェクトバンドルのエクスポート (`.json`)**: すべてのファイルセット、ターゲットFPGAパーツ番号、アクティブ最上位モジュール、セキュリティフラグをパッケージ化した自己完結型のポータブルJSONファイルを生成します。
- **ソースの追加...**: マルチフォーマットソース作成ウィザードを起動します。
- **プロジェクト設定＆セキュリティ...**: プロジェクト信頼モード、ストレージクォータ、データ分離、シミュレーション安全制限を設定します。
- **新規プロジェクトウィザード**: プロジェクト作成ウィザードを起動します。
- **プロジェクトを閉じる**: 未コミットの変更を失うことなくアクティブ状態を安全に保存し、ウェルカムローンチパッドに戻ります。

## プロジェクトのゴミ箱移動＆復元ライフサイクル

偶発的なデータ消失を防ぐため、Axiomは2段階の削除ライフサイクルを実装しています:
1. **ゴミ箱に移動**: ローンチパッド上の各プロジェクトカードの3点ドットメニューから実行できます。ゴミ箱に移動したプロジェクトは即座に `isTrashed: true` として永続化され、アクティブタブから消えてゴミ箱のバッジカウントが増加します。
2. **ゴミ箱内プロジェクトへのアクセス**: ローンチパッドの**ゴミ箱**タブをクリックすると、削除日時付きですべての破棄された設計が表示されます。
3. **プロジェクトの復元**: すべてのファイルと設定を保持したまま、プロジェクトをアクティブタブに復元します。
4. **完全削除**: アクリル確認モーダル（`ConfirmModal.tsx`）が表示されます。確認後、プロジェクトレコードを完全に消去し、関連するストレージディレクトリをファイルシステムから削除します。
