# Axiom静的リンター＆診断規則

Axiom EDAは、リアルタイムのメモリ内静的解析リンター（`crates/lsp/src/linter.rs`）を組み込んでいます。このリンターは抽象構文木とネットリスト接続性を解析し、コード記述中に合成ハザード、シミュレーション競合状態、電気的エラーを検出します。

---

## 診断ルールカタログ

```
+-------------------------------------------------------------------------------+
| Axiom Static Linter Dashboard (Problems Dock)                                 |
| 0 Errors | 2 Warnings | 1 Informational | Real-Time Latency: 1.8 ms           |
+-------------------------------------------------------------------------------+
| [AXIOM_W001] Line 42: Blocking assignment (=) inside clocked sequential block |
| [AXIOM_W007] Line 88: Case statement missing default branch                   |
+-------------------------------------------------------------------------------+
```

### 1. `AXIOM_W001`: 順序プロセス内でのブロッキング代入
- **重大度**: 警告
- **違反**: エッジトリガ型プロセス（`always @(posedge clk)`）内で `<=` の代わりに `=` を使用しています。
- **ハザード**: スレッドの実行順序によってレジスタ値が更新前または更新後に読み取られる、シミュレータ依存の競合状態が発生します。
- **修正方法**: `=` を `<=` に置き換えます。

### 2. `AXIOM_W002`: 組み合わせプロセス内でのノンブロッキング代入
- **重大度**: 警告
- **違反**: レベルセンスプロセス（`always @*` または `always @(a or b)`）内で `<=` を使用しています。
- **ハザード**: 不要なシミュレーションデルタサイクルオーバーヘッドを引き起こし、合成不一致の可能性を生じさせます。
- **修正方法**: `<=` を `=` に置き換えます。

### 3. `AXIOM_W003`: 未駆動ネット
- **重大度**: 警告
- **違反**: 宣言された `wire` やネットに継続的ドライバ（`assign`）、ゲート出力、またはサブモジュールポート接続がありません。
- **ハザード**: ネットが高インピーダンス（`Z`）または不定（`X`）のまま永続的にフローティング状態になります。
- **修正方法**: ドライバを追加するか、未使用のネット宣言を削除してください。

### 4. `AXIOM_W004`: 未使用信号
- **重大度**: 警告
- **違反**: 宣言されたレジスタやネットが書き込みまたは定義されていますが、下流の論理コーンで一度も読み取られていません。
- **ハザード**: 無駄なシリコン面積の浪費と不要なゲートの推論を招きます。
- **修正方法**: 未使用の信号を削除するか、目的の消費回路に配線してください。

### 5. `AXIOM_E002`: 複数ドライバによるネット競合
- **重大度**: エラー
- **違反**: 複数の継続的代入または同時ドライバが同一の `wire` を駆動しています。
- **ハザード**: 物理シリコン上での電気的短絡。シミュレーション上では競合不定（`X`）として評価されます。
- **修正方法**: マルチプレクサを挿入するか、単一のドライバのみがネットを制御するようにしてください。

### 6. `AXIOM_W006`: 透過ラッチの推論
- **重大度**: 警告
- **違反**: 組み合わせプロセスが、1つ以上の条件付き実行パスに沿ってターゲット変数を未代入のまま残しています。
- **ハザード**: 合成ツールが非同期レベルセンスラッチを推論し、深刻なタイミング収束の問題やクロックグリッチ感度をもたらします。
- **修正方法**: すべての `if-else` 分岐で全変数が代入されるようにするか、`always @*` ブロックの先頭でデフォルト値を代入してください。

### 7. `AXIOM_W007`: case文のdefault欠落
- **重大度**: 警告
- **違反**: `case` 文で `default:` 分岐が省略されています。
- **ハザード**: カバーされていない入力組み合わせにより、ラッチが推論されるかステートマシンがフリーズします。
- **修正方法**: `default: <safe_state>;` を追加してください。

### 8. `AXIOM_W008`: ビット幅の不一致
- **重大度**: 警告
- **違反**: 左辺のネットのビット幅が右辺の式のビット幅と一致しません。
- **ハザード**: 暗黙のMSB切り捨てや意図しないゼロ/符号拡張が発生します。
- **修正方法**: ビット幅を明示的に揃えるか、パートセレクトスライスを使用してください。
