# クロックバッファ＆入出力プリミティブ

クロッキングおよび入出力プリミティブは、グローバルクロック分配ネットワークと外部電気ピンインターフェースを制御します。

---

## グローバルクロックバッファ (`BUFG`, `BUFGCE`)

グローバルクロックバッファは、FPGAダイ全体にわたる高ファンアウト・低スキューの専用クロック分配幹線を駆動します:

### 1. `BUFG`
発振器ピンまたはPLL出力をグローバルクロックネットワークに接続するシンプルなグローバルクロックバッファ:
```verilog
BUFG u_bufg (
    .O (sys_clk_global),
    .I (sys_clk_pin)
);
```

### 2. `BUFGCE` (クロックイネーブルバッファ)
グリッチフリーのゲーテッドクロックバッファ。`CE` をデアサートすると、危険なラントパルスを発生させることなくクロック出力をLowにゲートします:
```verilog
BUFGCE u_bufgce (
    .O  (gated_clk),
    .I  (sys_clk),
    .CE (clock_enable)
);
```

---

## 入力＆出力バッファ (`IBUF`, `OBUF`)

入力および出力バッファは、内部論理と物理パッケージピンをインターフェースします:
- **`IBUF`**: 標準シングルエンド入力バッファ（`.O(internal_wire), .I(external_pin)`）。
- **`OBUF`**: 標準シングルエンド出力バッファ（`.O(external_pin), .I(internal_wire)`）。
- **`OBUFT`**: アクティブLowイネーブル（`.T`）付きトライステート出力バッファ。
