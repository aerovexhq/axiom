# DSP48 演算処理スライス

Xilinx FPGAには、高速ハードウェアデジタル信号処理スライス（7-Seriesの `DSP48E1` およびUltraScale+の `DSP48E2`）が組み込まれています。

---

## DSP48E2 アーキテクチャ (UltraScale+)

`DSP48E2` スライスの特徴:
- **$27 \times 18$ ビット 2の補数乗算器**: 単一クロックサイクルで広範なオペランド演算をサポートします。
- **48ビットアキュムレータ＆ALU**: 加算、減算、論理演算、累積演算を実行します。
- **専用プリ加算器**: 対称型有限インパルス応答（FIR）フィルタ用の27ビットプリ加算器。
- **パターン検出器**: ターミナルカウント、ゼロフラグ、オーバーフロー/アンダーフロー状態を検出します。

```verilog
DSP48E2 #(
    .USE_MULT("MULTIPLY")
) u_dsp (
    .P      (product_48bit),
    .A      ({3'b0, operand_a_27bit}),
    .B      (operand_b_18bit),
    .C      (48'h0),
    .CLK    (clk),
    .ALUMODE(4'b0000), // ADD
    .OPMODE (9'b000000101)
);
```

Axiom EDAでは、動作記述の乗算（`assign P = A * B;`）はテクノロジマッピング中に `DSP48E2` ハードウェアスライスへ自動的に推論されます。
