# コンフィギュラブルロジックブロック (CLB)＆論理プリミティブ

コンフィギュラブルロジックブロックには、Xilinx FPGAのコアとなるルックアップテーブル、キャリー論理、順序記憶素子が含まれています。

---

## ルックアップテーブル (`LUT1` 〜 `LUT6`, `LUT6_2`)

### 1. `LUT6_2` (デュアル出力6入力LUT)
モダンなXilinx CLBの基盤です。任意の単一6入力ブール関数（`O6`）、または入力 `I0` 〜 `I4` を共有する2つの独立した5入力ブール関数（`O5` および `O6`）を実装できます:

```verilog
LUT6_2 #(
    .INIT(64'h8000_0000_0000_0000) // 6-input AND gate
) u_lut (
    .O6 (and_out),
    .O5 (), // Unused in single-output mode
    .I0 (in0), .I1 (in1), .I2 (in2),
    .I3 (in3), .I4 (in4), .I5 (in5)
);
```

---

## 高速キャリー論理 (`CARRY4`, `CARRY8`)

専用の高速キャリーチェーンは、低速な一般配線にキャリー信号を通すことなく、高速な加算器やアキュムレータを実装します:
- **`CARRY4` (7-Series)**: プロパゲート（`S[3:0]`）、ジェネレート（`DI[3:0]`）、キャリーイン（`CI`）、キャリーアウト（`CO[3:0]`, `O[3:0]`）を備えた4ビット先行キャリーマクロ。
- **`CARRY8` (UltraScale+)**: CLBスライスあたり2倍のキャリー密度を提供する8ビット先行キャリーマクロ。

---

## フリップフロップ＆ラッチ (`FDRE`, `FDSE`, `FDCE`, `FDPE`)

Xilinxのスライスレジスタは、専用のクロックイネーブルと優先順位付きセット/リセットをサポートしています:

| プリミティブ | トリガー | リセット種別 | 優先順位 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `FDRE` | `posedge C` | 同期リセット (`R`) | リセット優先 | クロックイネーブル (`CE`) および同期リセット付きDフリップフロップ |
| `FDSE` | `posedge C` | 同期セット (`S`) | セット優先 | クロックイネーブル (`CE`) および同期セット付きDフリップフロップ |
| `FDCE` | `posedge C` | 非同期クリア (`CLR`) | クリア優先 | クロックイネーブル (`CE`) および非同期クリア付きDフリップフロップ |
| `FDPE` | `posedge C` | 非同期プリセット (`PRE`) | プリセット優先 | クロックイネーブル (`CE`) および非同期プリセット付きDフリップフロップ |

```verilog
FDRE #(
    .INIT(1'b0) // Power-on initial value
) u_ff (
    .Q  (q_out),
    .C  (clk),
    .CE (clk_en),
    .R  (sync_rst),
    .D  (d_in)
);
```
