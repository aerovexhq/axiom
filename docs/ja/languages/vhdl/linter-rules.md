# VHDL言語サーバー＆リンター規則

Axiom EDAには専用のVHDL言語サーバー（`crates/lsp/src/vhdl.rs`）が組み込まれており、Monacoエディタ内で構文検証、型整合性監査、設計規則チェックを直接提供します。

---

## VHDL診断ルール

| ルールID | 重大度 | 説明 | 修正方法 |
| :--- | :--- | :--- | :--- |
| `VHDL_W001` | 警告 | **不完全な感度リスト**: 組み合わせプロセス内で読み取られている信号が感度リストに含まれていません。 | 不足している信号を `process(...)` に追加するか、`process(all)`（VHDL-2008）を使用してください。 |
| `VHDL_W002` | 警告 | **意図しないラッチ推論**: 組み合わせプロセス内の不完全な `if-then-else` または `case-when` 分岐により、意図しない透過ラッチが推論されます。 | すべての分岐を網羅するか、条件分岐の前にデフォルト値を割り当ててください。 |
| `VHDL_E001` | エラー | **型の不一致**: 型変換を行わずに `std_logic_vector` を `unsigned` や `integer` に直接代入しようとしています。 | 明示的な `to_integer()`、`unsigned()`、または `std_logic_vector()` を使用してください。 |
| `VHDL_W003` | 警告 | **未使用の信号**: 宣言されたアーキテクチャ信号が代入も読み取りもされていません。 | 不要な信号宣言を削除してください。 |
| `VHDL_E002` | エラー | **複数ドライバの競合**: 複数の並行代入が同じ解決信号を駆動しています。 | 単一のマルチプレクス代入を使用してください。 |
